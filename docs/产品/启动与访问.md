# 启动与访问

## 选择使用入口

| 使用端 | 启动 | 资料与验证 |
| --- | --- | --- |
| Windows 独立桌面 | `SlowTune.exe`；源码见 [README](../../README.md#源码启动) | 自动建立本机会话，使用自己的 data，无需访问码 |
| PC 网页 | 启动服务后打开其地址 | 使用配置指定资料及访问策略 |
| 移动网页 | 手机打开可达的服务地址 | 与同服务 PC 网页共享资料，见[手机连接](../运维/运行维护.md#手机与局域网访问) |

独立桌面仅监听本机，手机需单独启动服务版。协议保留 `MUSIC_APP_*`、`X-Music-App`、`music_session` 及 `slow-listening:*` 标识。

## 欢迎与启动

### Windows 独立桌面

同一窗口显示本地欢迎页，完整呈现至少两秒并同时准备资料，就绪后自动进入。背景和主题缓存于 data；失败保留重试、日志与退出。设置的本地资料入口用于查看目录和歌单备份。

### 服务版 PC 与移动网页

入口先读取公开策略：有效会话直接准备数据，需要验证时输入访问码，免验证时通过 POST 建立浏览器独立 HttpOnly 会话。欢迎图失败回退内置风景及纯色入口。

启动至少展示约 1.5 秒；状态、资料库、账号、关注、发现和来源握手并行。只有服务状态与握手阻塞进入，握手限时 10 秒，歌单及推荐后台继续加载。请求结果交接首页，避免重复读取；资料未就绪时禁用保存，失败可局部重试。不会自动播放。

## 自定义欢迎图

「外观 → 欢迎页」提供内置风景、自定义图和纯色。上传 JPG／PNG／WebP 原图不超过 12 MiB，浏览器重编码最长边 2560px；服务端检查格式、尺寸与 3 MiB 上限，不保存照片元数据。

电脑与手机分别设置水平／垂直焦点，支持拖动、滑块、0–70% 遮罩、电脑面板位置及深浅预览。上传、恢复、导入先预览，保存后生效，取消恢复已保存状态。

设置及一张自定义图按用户空间保存在 `database + '.settings.sqlite'`；切内置／纯色保留该图，替换图片覆盖旧图。欢迎页与图片登录前可读，同服务设备都能看到。

`slowtune-welcome.json` 单独备份图片和构图，不含访问码、验证策略或账号；导入后预览并保存。完整备份见[运行维护](../运维/运行维护.md#资料备份)。

## 访问码与验证方式

仅服务版提供「启动与访问」。首次从配置 `accessKey` 初始化，之后用随机盐及 scrypt 摘要保存；配置改动不覆盖已经保存的策略，接口不返回明文或摘要。

新访问码为 6–256 字符。修改验证方式或访问码均需当前访问码，失败限流；仅切验证方式可不填新码。保存后当前会话保留，其他会话及其未完成任务撤销，已提交事务不回滚，B站账号不退出。

默认开启验证。关闭后能连接服务的设备可进入共享资料，但 API 仍校验独立会话，再改策略仍需当前访问码。

忘记访问码时先停止服务，执行 `npm run reset-access`，再启动并修改。命令要求已有构建且实例已停止，将访问码恢复为配置值并重新开启验证，不清空资料。

## 实现与验证

入口在 `src/EntryGate.tsx`、`startup.ts`、`WelcomeScreen.tsx`；设置在 `WelcomeSettings.tsx`、`AccessSettings.tsx`；服务在 `server/startup-settings.ts` 和 `index.ts`。

回归选择 `startup-settings`、`startup-preload`、`host` 和 `source-settings` 用例；浏览器检查覆盖预览保存、会话撤销、手机键盘与失败重试。执行前提见[验证规范](../开发/验证规范.md)。
