# 启动与访问

中文名「慢听」，英文品牌「SlowTune」，工程包名 `slowtune`。当前配置和协议使用 `MUSIC_APP_*`、`X-Music-App`、`music_session`，浏览器偏好使用 `slow-listening:*` 标识；公共依赖包沿用真实名称。

## 欢迎与启动

以下访问码与共享设置属于服务版。独立桌面在同一主窗口显示启动页，慢听标识、文案与加载状态统一居中略偏上，背景沿用欢迎图、图片焦点与遮罩设置；完整呈现后至少停留两秒并同时准备资料，就绪后自动进入播放器。内部会话由宿主建立，不展示配置选择或访问码。桌面欢迎图与主题缓存在程序旁 data，启动失败保留重试、日志和退出。设置中的“本地资料”提供资料位置及备份，服务版的 PC／移动网页继续使用下述规则；移动 Web 的界面与交互正在迭代。

欢迎页使用背景图与独立面板，支持深浅主题。电脑面板可靠左、居中或靠右；手机面板位于下半部并允许在短屏或键盘打开时滚动。图片失败回退到内置风景，再失败仍可使用纯色底上的入口。

入口先读取公开的启动策略。有有效访问会话时直接准备数据；需要验证且无会话时展示访问码表单。关闭验证后，入口通过 POST 建立每个浏览器独立的随机 HttpOnly 会话，业务接口仍校验该会话。

启动至少展示约 1.5 秒；服务状态、资料库、B站账号、关注名单和B站发现批次同时读取，来源协议握手并行进行。仅服务状态与握手阻塞进入；歌单收藏和推荐等内容继续在后台完成。首页接收同一批请求的结果／Promise，不重复读取首次数据。歌单读取较慢或失败不阻塞搜索、发现及明确来源点播，歌单页独立提供加载、失败与重试；资料尚未读取时保存操作不可用。约 3 秒仍未进入时保留加载说明；必要请求有超时与重试。来源协议握手限时 10 秒，进入后的搜索与取源沿用各自业务预算，不受该握手期限截断。不会自动开始播放。

## 自定义欢迎图

「设置 → 外观 → 欢迎页」提供内置风景、自定义图片和纯色。JPG、PNG、WebP 原图上限 12 MiB；浏览器重新编码为最长边不超过 2560px 的图片，服务端独立检查格式、尺寸及 3 MiB 大小上限。不保存原始照片元数据。

电脑与手机分别保存水平／垂直焦点，可拖动预览或用滑块调整。另有 0–70% 背景遮罩、电脑面板位置、电脑／手机与白天／黑夜预览，以及登录表单预览。上传、恢复默认和导入均先改预览，点击保存后才对服务生效；取消恢复上次保存状态。

欢迎设置和一张自定义图片保存在现有 `database + '.settings.sqlite'` 中，按 `userSpace` 隔离；升级不会覆盖。切换内置风景或纯色时保留已上传的那张图，方便切回。替换自定义图片会替换旧图片。欢迎页和图片在登录前可读取，连接此服务的设备都能看到；上传前应了解这一展示范围。

欢迎页单独导出为 `slowtune-welcome.json`，包含图片和构图，不含访问码、验证方式或账号。导入文件后先预览，再保存。原有歌单收藏 JSON 快照范围不变。

## 访问码与验证方式

「设置 → 启动与访问」可切换进入验证和修改访问码。首次从配置 `accessKey` 初始化，之后以独立随机盐和 scrypt 摘要保存在服务的设置库中；接口不返回明文、盐或摘要。后续改动配置文件的 `accessKey` 不覆盖设置中已经保存的访问码。

新访问码为 6–256 个字符；修改时输入当前访问码、新访问码和确认值。只切换验证方式时可将新访问码留空。勾选发生变化后即可点击保存；当前访问码放在进入方式下方，未填写时提交会定位到该必填项。保存验证方式或访问码都校验当前访问码，失败尝试限流。保存后当前浏览器保留连接，其他旧会话失效并取消其任务，包括未完成的请求体读取、来源调用与资料提交；迟到的来源结果不能继续写入，已完成的事务不回滚。旧会话再次请求时返回入口；关闭验证时可以自动建立新的独立会话。B站共享登录不被退出。

默认开启访问验证，升级不会自动关闭。关闭后能够连接本服务的设备可以进入和使用共享资料；访问策略的再次修改仍需当前访问码。免验证时诊断页隐藏「退出当前浏览器登录」，避免退出后立即自动进入。

忘记访问码时，在服务电脑上先停止当前实例，再执行 `npm run reset-access`。此命令将访问码恢复为当前配置中的 `accessKey` 并重新开启验证；要求已有正式构建，并拒绝在运行实例存在时操作。随后重新启动，进入设置修改。此恢复只影响访问策略，不清空歌单、收藏或欢迎图。

## 实现与验证

- 入口与请求交接：`src/EntryGate.tsx`、`src/startup.ts`、`src/source-client.ts`、`src/WelcomeScreen.tsx`。
- 设置界面：`src/WelcomeSettings.tsx`、`src/AccessSettings.tsx`。
- 服务策略与图片：`server/startup-settings.ts`、`server/startup-types.ts`、`server/index.ts`。
- 自动检查：`tests/startup-settings.test.mjs` 面向存储、真实 HTTP、权限、会话撤销与重启；`tests/startup-preload.test.mjs` 面向入口预加载与请求交接；Host 和来源设置分别由现有 `tests/host.test.mjs`、`tests/source-settings.test.mjs` 检查。握手限时、请求取消及完整页面操作按当前源码和受影响回归核对，不引用不存在的测试文件。
- 浏览器检查使用独立服务、临时资料与测试访问码，覆盖电脑／手机布局、图片预览与保存、访问验证和会话撤销；真实来源与实体设备另行验收，方法见[验证规范](../开发/验证规范.md)。
