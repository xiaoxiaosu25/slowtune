## 选择使用入口

| 使用端 | 启动与资料 | 界面与验证 |
| --- | --- | --- |
| Windows 独立桌面 | `SlowTune.exe`，使用自己的 `data/`；源码启动见 README | 自动进入、悬浮歌词、本地资料，无需访问码 |
| PC 网页 | 启动服务后打开其地址，资料由服务配置指定 | 侧栏导航、底部歌词，遵循服务访问策略 |
| 移动网页 | 手机打开可达的服务地址，与同服务 PC 网页共享资料 | 发现／音乐库／我的、迷你播放器与独立播放页，遵循服务访问策略 |

独立桌面仅监听本机，手机需单独启动服务版，见[手机与局域网访问](../运维/运行维护.md#手机与局域网访问)。

## 欢迎与启动

### Windows 独立桌面

同一窗口显示本地欢迎页，完整呈现至少两秒并同时准备资料，就绪后自动进入。重复打开唤起原窗口，最小化继续播放，关窗保存并退出自己的服务。失败时提供重试、打开日志与退出；设置中的「本地资料」可查看目录和备份歌单。

### 服务版 PC 与移动网页

入口先读取访问策略：有效会话直接准备数据，需要验证时输入访问码，免验证时自动建立当前浏览器的访问会话。欢迎图失败回退内置风景及纯色入口。

启动时显示欢迎页，进入后歌单及推荐可继续加载。资料未就绪时禁用保存，读取失败可局部重试；首次进入与刷新均不自动播放。

## 自定义欢迎图

「外观 → 欢迎页」提供内置风景、自定义图和纯色。可上传不超过 12 MiB 的 JPG／PNG／WebP 原图，处理后不保存照片元数据。

支持拖动、滑块调整水平／垂直焦点、0–70% 遮罩、电脑面板位置及深浅预览。服务网页可分别编辑电脑和手机构图，并预览访问码表单；Windows 程序编辑本机电脑构图。上传、恢复、导入先预览，保存后生效，取消恢复已保存状态。

服务版欢迎图与构图由同一服务共享，登录前即可显示。切内置／纯色保留自定义图，再上传图片覆盖旧图。

`slowtune-welcome.json` 单独备份图片和构图，不含访问码、验证策略或账号；导入后预览并保存。完整备份见[运行维护](../运维/运行维护.md#资料备份)。

## 访问码与验证方式

服务版在「设置 → 启动与访问」修改验证方式和访问码。首次访问码由服务配置提供，之后以保存的策略为准；修改配置不会覆盖已保存的访问码。

新访问码为 6–256 字符。修改验证方式或访问码均需当前访问码，失败限流；仅切验证方式可不填新码。保存后当前会话保留，其他会话及其未完成任务撤销，已提交事务不回滚，B站账号不退出。

默认开启验证。关闭后能连接服务的设备可进入共享资料，但 API 仍校验独立会话，再改策略仍需当前访问码。

忘记访问码时按[恢复服务访问码](../运维/运行维护.md#恢复服务访问码)操作；恢复后重新进入并修改访问码。
