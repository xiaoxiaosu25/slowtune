# 产品功能

## Windows 桌面入口

Windows 桌面版打开后在同一窗口显示欢迎页并自动进入，无需选择配置或输入访问码。源码“一键启动”使用当前构建，重复点击唤起已有窗口；开发重建使用 desktop:restart。资料、队列、主题、窗口和歌词偏好统一保存在程序旁 data；设置提供“本地资料”，不再展示服务配置或访问验证。关窗退出自己的内部进程，最小化继续播放，不影响服务版。悬浮歌词继续支持拖动、锁定穿透、托盘解锁、字号颜色、单双行、翻译和真实逐字时间；共用唯一播放器。启动与交付见[README](../../README.md#源码启动)。

桌面设置中的“运行信息”可手动复制版本、运行环境、来源状态和错误分类，未知字段明确标记；不复制凭据、账号身份、媒体地址、私人路径或原始日志，不自动上传。桌面资料和账号与服务版各自保存；退出应用保留账号登录。播放与界面偏好、窗口／歌词状态和欢迎图合并后异步保存，失败保留最后文件及内存修改并提示重试，正常退出等待必要落盘。状态文件读取失败时保护原文件、阻止启动并提供重试及资料目录入口；退出失败明确显示阶段，已释放播放时提供恢复页与重试退出。完整备份须退出后复制整个 data，“歌单 JSON 导入与导出”只覆盖歌曲资料。

本文描述当前网页与 [server/index.ts](../../server/index.ts) 已装配的行为。收藏、歌单、版本、队列、备份、维护与同步已采用新歌曲模型。真实来源和设备表现按[验证规范](../开发/验证规范.md)单独验收。

## 当前功能速览

桌面页面或专用管理界面无法显示时，可在受影响区域重试，或通过导航返回其他页面；当前音频继续播放。歌曲管理、歌单封面与版本／歌词管理首次打开时按需加载，失败提供重试或关闭。恢复后已保存资料保留，受影响区域未保存的输入可能需要重新填写。

| 模块 | 当前能力 | 使用边界 |
| --- | --- | --- |
| 发现与搜索 | B站推荐、可选 YouTube 精选、来源搜索、筛选和指定优先结果 | 来源开关、账号、网络与平台结果影响可用性 |
| 音乐榜单 | 多平台榜单、版本匹配、单首与整榜播放 | 榜单歌曲通过当前支持的视频来源匹配播放 |

| 收藏与歌单 | 歌曲资料、多版本、默认／固定版本、重复成员、重排、批量添加、维护及新格式备份 | 收藏以歌曲身份组织；合并、移动和删除先预览影响 |

| 设置与访问 | 外观、欢迎图、访问验证、来源、推荐、诊断和声明 | 服务设置共享，浏览器外观独立 |

## 产品与设备范围

慢听有 PC 网页端、移动网页端和独立 Windows 桌面端。前两者属于服务版并共享同服务资料；移动 Web 正在恢复界面迭代。桌面自己启动并使用本地 data，与服务版的启动、配置和资料分开，复用业务与播放实现。当前默认只做源码构建验证，明确要求时才生成免安装包；没有独立 Android／iOS 客户端或下载与离线音频功能。

服务使用配置中的一个 `userSpace`；客户端不能自行选择用户空间。连接同一服务的设备共享歌曲资料、歌单、收藏、应用关注、推荐偏好、来源设置、B站登录、欢迎图与访问策略。队列、主题明暗和配色属于各自浏览器，不自动跨设备同步。详见[架构与数据](../开发/架构与数据.md)。

## 导航、发现与搜索

桌面主导航为发现、音乐榜单、关注、歌单，另有独立设置页与正在播放页。移动 Web 底部导航为发现、音乐库、我的；发现页内切换推荐、音乐榜单与关注，音乐库先展示收藏和全部歌单，再进入歌单详情，我的集中进入账号、外观、来源、推荐、数据与关于设置。搜索桌面使用弹窗，手机使用独立全屏页面，与浏览页共用迷你播放器；返回保留原页面与歌单，前进恢复当前页面会话内的搜索内容，从完整播放返回也保留搜索上下文。两端接入同一套业务。

发现页展示 B站推荐、启用后的 YouTube 音乐精选，以及应用内关注作者的最近更新。B站登录时使用账号推荐分支，未登录时使用匿名音乐分区分支。榜单有独立页面。

手机榜单从搜索或完整播放返回时保留当前平台、榜种／期次与分页。关注的作者、最近更新、作者合集与投稿进入浏览历史；返回恢复对应层级、分页与阅读位置，长列表读取后再恢复滚动。页面内的返回按钮可回到所属关注页或作者合集，浏览器前进可恢复作者内容。主动点击发现中的「关注」回到关注首页。

发现栏目统一使用 `discoverySize = 12`，优先展示新推荐；新推荐不足时用符合当前规则的旧推荐补到 12 首。桌面去重后仍不足时保留占位并解释；手机只展示实际可用内容，封面横向浏览，列表先显示四首并可展开全部。手机栏目标题旁直接播放全部，换批／刷新、加入歌单、封面／列表选择、地区和获取说明收进栏目操作面板，错误仍在正文显示。没有数量档位选择。手机和桌面的栏目视图偏好分别保存。YouTube 精选保留地区选择。

推荐批次由服务准备，普通读取和主动换批分开；页面刷新不等同于每次重抓。启动可恢复上次成功内容，并显示后台准备或保留内容的状态。推荐展示仅在当前页面有效可见时确认；预览、取消和迟到结果不当作展示记录。

桌面 B站账号推荐以有效的新分区编号为准，明确属于非音乐分区的视频不会因旧音乐编号或分区名称而入选；没有有效新编号时才兼容旧编号，没有有效编号时才按分区名称筛选。音乐教学、乐评和盘点继续排除。桌面推荐批次按筛选策略版本隔离；策略或偏好更新后，新推荐不足时仍可读取同一账号的历史候选，重新校验当前分区并按当前偏好筛选后补齐，不直接采用旧的筛选结果。手机路径保持现有行为。

关键词搜索支持 B站和启用且可用的 YouTube 视频来源，分页按来源独立处理。B站混入的课程、直播等明确非视频卡片不作为歌曲结果，也不使同页视频搜索失败。来源链接入口接收库能识别的视频、BV 与公开歌单引用；不承诺任意 URL 或短链解析。多 P 视频经元信息规范化为真实分 P 身份。

收藏、歌单、榜单、关注作者／更新／内容、搜索、分 P、批量导入预览和失效歌曲清单共用紧凑分页，默认每页 30 条，可选 20／30／50／100，按列表类型保存在当前浏览器。已知总量的列表支持首页、上一页、下一页、尾页和输入页码直接跳转。只有继续游标的远端列表按需补取，允许回翻已读页面；总页数未知时显示省略号并禁用尾页，不把已读末页当作来源尾页。每次补取有界，筛选后内容很少时可继续按下一页读取。发现页仍为每栏最多 12 首；播放队列和评论保持原有滚动／展开方式。

搜索按照「设置 → 推荐偏好 → 搜索与自动选歌」的配置筛选分区、版本与排除词，保持平台原始相对顺序。提示数量仅统计当前已加载结果；「显示全部／恢复筛选」不重新搜索、不清除分页，仅改变本次展示，显示全部时标注筛选原因。播放全部与加入歌单使用当前显示范围。新搜索使用保存的默认开关；公开歌单链接列表不套用搜索筛选。

桌面从榜单或歌曲资料打开搜索时，使用“歌名 歌手”并填入可编辑搜索框；歌手缺失时只用歌名。手动输入按原关键词搜索。公开搜索与分区读取使用匿名访客，不附带 B站登录账号。移动端保持既有搜索行为。

搜索结果的更多操作支持「自动匹配时优先选此结果」，保存适用歌名／搜索词、可选歌手和稳定视频／具体分 P 引用。它只作用于需要搜索的自动匹配；本次明确版本、歌单固定版本和歌曲默认版本优先。同歌名与歌手的匹配偏好优先于明确保存的纯歌名偏好，普通播放和收藏不会隐式建立绑定。优先结果单独展示，平台搜索列表不因指定而重新排序；为已保存歌曲搜索添加版本时只展示添加入口，不展示搜索匹配偏好。偏好保存在服务端，同服务设备共享，可在偏好中取消。恢复默认先载入草稿，保存后生效，保留匹配偏好；升级不自动覆盖用户配置。

## 音乐榜单

| 平台 | 当前榜单 |
| --- | --- |
| 网易云 | 热歌、新歌、飙升 |
| QQ | 热歌 |
| B站 | 热歌、可用历史期次 |
| Apple Music | 中国区热门歌曲 |

榜单展示来源返回的歌名、歌手、封面、顺序与更新信息；缺失字段保持未知。缓存按 `refreshAfter` 等来源周期信息复用，读取失败时可保留上次成功内容并提示。

桌面榜单的爱心随资料库显示收藏状态，保存期间显示等待并防止重复提交；再次点击已收藏歌曲可取消收藏。刷新或切换榜单后仍按歌曲的榜单来源标识读取状态，收藏本身不触发音轨搜索或播放。

点击歌曲主体（歌名、封面）或“直接播放”调用同一服务端匹配流程；独立搜索按钮保留歌名与歌手上下文供用户指定版本。匹配首先读取用户指定的稳定引用。桌面需要自动选源时，先以“歌名 歌手”搜索 B站当前页，成功但没有合格候选再以原歌名查询；歌手缺失时只查询一次歌名。每页按来源顺序选第一条通过分区、版本、排除词与原歌名／歌手核验的结果，回退不放宽规则。移动端沿用原歌名查询。开启严格核验时，短歌名缺少歌手信息不自动匹配；无可靠 B站候选且 YouTube 可用时再以相同流程查该来源。来源错误不当作空结果；分区查询只有明确的内容不存在可降为未知，未附 HTTP 状态的来源故障同样保留错误、停止自动回退及整榜继续请求。指定版本失效保留绑定并提示重新选择，不静默换曲。

手机榜单以歌曲主体作为播放入口，长标题最多两行，右侧保留收藏与搜索。手机歌曲与版本面板分别标识当前播放版本与默认版本，切换显示准备及结果反馈；为正在听的歌曲选择另一版本时原位替换当前队列项，准备失败保留原播放。仅浏览版本或设为默认不会主动播放。

桌面自动选源还须实际读取候选音频的一小段；准备接口成功不代表媒体流可播放。候选媒体明确不存在、受限、过期或不支持时，继续检查同页后续合格结果，再按既有顺序回退查询。命中的缓存候选也重新检查音频；网络、超时、限流、登录或服务故障停止本次匹配。手动明确选播、歌曲默认／固定版本及已指定的匹配偏好保留原选择，不因此改用其他视频。移动端保持既有行为。

默认放行电台·歌单、MV、原创音乐、音乐综合；现场、饭拍、翻唱、演奏、VOCALOID、AI及特殊版本默认要求明确搜索，教学、乐评、非音乐与未知分区默认仅供手动选择。识别优先使用 B站新版分区 ID，再兼容旧版字段，不依赖可能为空的分区名称。所有策略在偏好中可修改；只筛选、不按分区或关键词重新打分排序。自动匹配缓存随配置修订、来源启停及账号上下文失效；已解析的榜单队列再次选择时也重新检查指定版本。

“播放全部”按当前完整榜单建立待解析队列，播到该首才搜索和取源。单项失败会记录并按规则跳过；鉴权、网络、限流、服务不可用等终止条件会停止继续请求。

## 播放与队列

- 使用公共 player 的状态、队列和媒体会话能力，当前输出后端为网页原生 `<audio>`。
- 单首点播保留原队列：已有同来源与分 P 的条目时复用，优先当前项；否则插入当前项之后并立即从头播放。收藏／歌单点播复用同一歌曲及固定版本策略的已有实例，批量入队仍保留重复成员。空队列只加入该首。复用榜单项时，本次点播固定使用选中的具体引用，不被新指定版本替换；之后再次从队列选择该榜单项时仍检查最新偏好。取消的点播不影响后续选择。
- 明确的“播放全部”替换队列；播放范围由该入口传入。发现页是展示的最多 12 首，收藏／歌单是完整筛选范围，搜索是当前已读取且符合筛选的范围，榜单是当前完整榜单。关注更新与 B站作者内容明确使用“播放本页”，YouTube 作者内容使用“播放已读”。分页不改变队列的 500 项上限。
- 队列最多 500 项，支持增删、重排、上一首／下一首、顺序、随机、列表循环和单曲循环。队列与持久歌单分别编辑。
- 用户点播、切歌和选择队列歌曲从头开始；暂停后继续当前进度，当前播放中的地址刷新保留现场进度与播放意图。
- 媒体失败且自动恢复准备失败后，“重试播放”继续同一队列项的确切来源和故障前进度，采用最新播放／暂停意图。暂停时重试仍保持暂停；准备期间的暂停指令继续有效。取消或切歌使未完成重试失效。
- 刷新或重新打开只恢复队列、选中项、模式、音量、倍速和静音，不恢复曲目进度，不自动取源或发声。睡眠定时不跨页面会话保存。
- 播放时钟只更新进度与缓冲范围；队列和控制偏好发生变化时才保存浏览器队列。独立准备另一首歌曲或版本时，当前仍在发声的音频与音波继续运行，准备失败保留现场。
- 进度拖动先预览，结束拖动后实际定位；支持快退／快进、倍速、静音和睡眠定时器。空格切换播放／暂停，播放页左右键前后 5 秒、J／L 前后 10 秒；输入、弹窗与部分控件聚焦时不拦截快捷键。
- 桌面睡眠定时支持倒计时、自然播完 N 首和播完当前曲。快捷设置点击立即生效；自定义修改点击“开启定时”或“应用设置”后才生效，并替换原规则。按首数包含当前曲剩余部分，手动切歌或直接拖到末尾不计数；“播完当前曲”在手动切歌后等待新的当前曲。暂停不停止倒计时；到期阻止尚未完成的歌曲准备继续起播。结束动作支持暂停、停止，独立桌面另支持“退出慢听”。
- 桌面正在播放页保留黑红唱片、原图、居中裁剪方形、慢转圆形、横向音波与圆形音环六种展示，点击展示区切换，Enter／空格均可操作。歌词通过歌曲操作区「词／更多」中的「词」直接进入独立沉浸模式。手机播放页使用独立布局，唱片等六种封面展示与直接歌词切换分别操作；控制区集中于下半屏。浏览时使用 72px 迷你播放器打开完整播放页或队列，迷你条与唱片页不显示歌词预览，歌词通过按钮进入完整阅读区；返回浏览页恢复进入前的位置。未保存有效偏好时默认唱片；桌面遇到既有歌词样式偏好时显示唱片，不改写该偏好。其他选择继续沿用，偏好保存在当前浏览器并在同源标签页同步，切歌和切换样式保留播放现场。唱片使用纯装饰红色文字标签，唱片与两种音波均不嵌入歌曲封面；方形与圆形缩小居中，与其他样式保持协调留白。桌面与手机的唱片和圆形封面播放时始终慢转，不随系统减少动态设置关闭；暂停／缓冲、页面隐藏或进入沉浸歌词时保留角度，恢复时接续旋转；横向音波以固定水平中线的真实频谱柱呈现，保留轻微呼吸缩放，不增加波浪偏移，圆形音环独立保留，中心采用与默认唱片相同的酒红纸质标签、印字与轴心，保持静止并随可用空间缩小，外环继续跟随主题，暂停／静音时分别回落到低线／细圆环，隐藏或离开音波模式时停止绘制。桌面与手机的音波与音环在播放时持续呈现真实频率，不随系统减少动态设置关闭，不显示减少动态提示或额外启用开关。分析不可用时保留播放并提示。
- 手机完整播放页优先显示已登记的歌曲名与歌手，来源平台、当前版本名与版本数量入口放在独立一行；长歌名与歌手最多两行，短屏收为一行。点击标题可查看真实来源原标题、完整歌手与版本信息；资料缺失时保留原标题及已有作者入口。小屏和横屏可打开版本、阅读歌词与编辑队列，保留当前音频和播放进度。
- 当前来源关闭时跳过其队列条目；播放中的 YouTube 被关闭时停止对应来源并按可播放队列接续。资料保持保存。

实际可用音轨由来源返回，并按浏览器 `canPlayType` 筛选；无损优先，其余按返回码率选择。页面展示真实格式和可用码率／采样率，不凭名称宣称 Hi-Res；当前没有手动音质选择界面。

多 P 操作支持当前、勾选、整组、从本 P 连续播放，以及相应入队、收藏和加入歌单。可按视频记住单 P／整组偏好；整组展开在当前播放项仍有效时保留其播放现场。

## 歌词

实际开始加载播放后自动读取当前版本已选歌词与偏移，没有选择时按歌名、歌手和时长查询网易云与 LRCLIB，无须点击歌词。已存版本须先取得版本资料再自动匹配，资料读取较慢或失败时仍可恢复已选歌词、人工搜索或导入，未收藏来源可直接查询。明确的「歌手《歌名》」标题可提取搜索信息，桌面还支持「《歌名》歌手｜说明」，宣传文案、合集和翻唱原唱署名不作为后置歌手；已知演唱者优先，上传者不会充当歌手。桌面按明确登记的别名识别同一歌手，目前包含周杰伦／周傑倫／Jay Chou，手机保持原匹配规则。仅采用歌名／版本一致且有歌手或时长佐证的结果；同名歌手歧义、明显时长差异、演唱者未知的已标记翻唱保留人工选择。自动查询失败不影响音频，也不覆盖查询期间其他页面保存的歌词。

桌面浏览器版底部歌词默认开启，可在「更多播放选项」关闭，偏好在当前浏览器保存并同步同源标签页。播放页底部突出当前句、弱化下一句；宽屏浏览其他页面时在播放条上方默认只显示当前句，可用右侧按钮展开下一句或已开启的译文，再次点击收起；歌词条按展开状态为页面、侧栏和队列留出空间。手机仅在完整歌词视图显示歌词，不提供底部歌词开关；已有桌面偏好保持保存。Electron 桌面程序不显示这块底部歌词及开关，默认开启独立桌面悬浮歌词，之后记住手动开关；当前歌曲没有实际歌词、正在加载或为纯音乐时自动隐藏整个悬浮窗，有歌词后自动恢复，手动关闭时不自动开启。桌面沉浸歌词及原有入口保留，歌词匹配和播放同步逻辑保持不变。

宽度大于 760px 时，「词」一次点击覆盖整个网页可视区域，左侧显示封面、歌名和作者，右侧显示左对齐的大字歌词，底部为居中的紧凑悬浮控制卡片，左右及底部保留留白。左侧沿用进入前的唱片／原图／方形／圆形／音波／音环选择，点击继续循环切换，返回普通模式后保留最新选择；歌名可展开完整标题，来源详情底部的「选择版本」入口与灰色来源行共用普通播放页行为。背景使用低饱和封面环境色，隐藏应用顶栏。底栏保留进度、播放、模式、音量、队列、收藏、「词」和更多；倍速、定时、快进退、翻译及歌词设置在更多中。队列／评论覆盖打开，不挤压双栏。

沉浸歌词与现有展示共用歌词会话及实际媒体时钟，自动匹配不自动进入。当前句位于阅读区约 45%，上下文弱化并在边缘渐隐；真实逐字时间逐字推进，普通 LRC 整句高亮，纯文本静态阅读。点击有时间的歌词按既有偏移定位，保留暂停意图。手动浏览停止 5 秒后恢复跟随，也可立即「回到当前行」。暂停、缓冲、拖动和倍速跟随真实位置，减少动态效果时保留同步高亮并关闭缩放、模糊及平滑滚动。渲染失败保留可读正文、重试与播放控制。

点击左上角收起、再次点击底栏「词」或按 Esc 返回并恢复按钮焦点；Esc 优先关闭菜单／弹窗。切歌保持沉浸模式，离开播放页、刷新或窗口缩至 760px 及以下返回普通模式。原页面保留挂载，布局不变，音频不重建；控制偏好与底部歌词恢复原状。被覆盖的普通封面暂停绘制，歌词模式中的封面按当前播放状态旋转或显示实时音波，共用同一音频分析图。

桌面播放页通过来源详情底部的「选择版本」入口打开「版本与歌词」侧边面板，两个标签分别管理播放版本和当前音源歌词，打开后仍可操作播放器。版本支持搜索、试听、保存和明确设为默认；试听原位切换当前队列项，不自动收藏或改默认，准备失败保留原播放。来源行展示平台，悬停或聚焦可查看原始标题、UP主与分P并打开或复制链接。主控制依次为模式、上一首、播放／暂停、下一首和收藏；倍速、定时及队列保持原有操作，去掉外围胶囊。

桌面沉浸歌词提供「更换歌词」「校准时间」，无歌词时直接查找或导入；更多菜单也可进入歌词管理。手机完整歌词视图在「暂无匹配歌词／歌词暂不可用」旁提供「查找或导入歌词」，直接打开已有选择弹窗，保留候选与草稿；失败时还可原地重试读取。首次读取失败时，手动入口会重读当前选择，取得修订后才能保存；关闭或完成恢复仍留在歌词视图，播放与队列继续保留。纯音乐显示独立提示，加载中不显示失败操作，未播放时提示先播放音乐。「更多播放选项 → 歌词设置」的原入口继续保留。人工候选先预览再采用，提供方部分失败保留其他结果。支持最多 128 KiB 的 UTF-8 LRC／文本文件及粘贴正文；时间可提前／延后 0.5 秒或填写秒数，即时预览后保存，关闭侧边面板撤销未保存偏移，正数表示延后。纯文本不提供时间校准。整体偏移不能修正不同编曲的段落差异，此时应换候选。清除选择后，下次播放或主动重新匹配会再次查询。

歌词与偏移属于实际播放的 BV＋分 P／YouTube 视频；同歌不同版本分别保存，未收藏来源也可使用，不隐式收藏或建立永久歌曲资料。切换展示及浏览页面不会重复匹配或重载音频。歌词选择保存在独立服务数据库，当前不纳入歌曲资料快照；完整实例备份可保留。当前取词主要提供逐句时间，支持呈现已有逐字数据，不新增逐字取词来源、罗马音或桌面悬浮歌词。

## 歌曲、版本、歌单与备份

“我的收藏”以歌曲 ID 幂等保存，收藏有自己的 ID、时间与顺序。自建歌单支持创建、改名、删除、增删歌曲与重排；成员有独立 entryId，同歌可重复，每个成员可固定版本或跟随歌曲默认版本。

桌面歌单页以当前歌单名作为主标题，封面、数量与「播放全部」集中展示；「管理」菜单提供新建歌单、歌曲管理和导入／导出，自建歌单另有改名和删除。搜索与来源筛选位于歌曲列表上方，多版本数量入口位于歌曲行右侧。侧栏仍可直接新建歌单。手机音乐库将收藏与自建歌单放在同一“我的歌单”列表，统一展示封面、名称与数量，可直接新建歌单；音乐库管理面板提供资料库维护和导入／导出。点入歌单后平铺歌曲，标题旁仍可从底部切换歌单，管理面板提供新建、资料库维护和导入／导出，自建歌单另有改名与删除。歌单详情进入浏览历史，刷新恢复当前歌单，返回音乐库总览；跨桌面布局切换保留当前歌单。

桌面可点击收藏／歌单主封面「更换封面」，上传不超过 12 MiB 的 JPG、PNG、WebP，或从当前列表歌曲封面中搜索选择；支持正方形裁剪、拖动、方向键微调、缩放与预览，保存后主封面和侧栏同步显示。手动封面保存为独立图片，删歌、排序及歌曲资料更新不改变它；「恢复自动封面」改用第一首有封面歌曲，没有可用图片时显示占位。取消不写入，失败保留选择，修订冲突核对当前封面后重试。收藏与各歌单分别保存，图片随资料库快照导出／恢复；手机保持原封面和操作。

歌曲保存标准歌名、歌手和字段保护；版本保存确切来源、原标题、上传者与时长。可以编辑标准歌名／歌手、版本名称／类别／演唱者及默认版本。修改默认不打断当前声音；改名更新队列展示与系统媒体信息，不重建队列。写入携带当前修订，冲突自动重读并保留修改过的字段草稿，由用户核对后采用当前修订。

桌面歌曲使用独立的网易云目录资料显示统一歌名、歌手和专辑／单曲封面，播放版本保留原标题与来源封面。桌面在线、页面可见且没有打开弹窗时，逐首补齐收藏与歌单中的新旧歌曲；只自动采用歌名、歌手明确吻合且没有其他录音室发行候选的资料，优先录音室原版，歧义、合集与串烧留待选择。人工改过的歌名、歌手和封面继续保留，不同歌曲即使匹配同一目录 ID 也不自动合并。歌单、歌曲窗口、队列、播放条、播放页及系统媒体信息共用桌面显示；更新不重新取源或中断声音。手机沿用原资料与交互，不启动目录补齐。

在「歌曲与版本 → 歌曲资料 → 匹配或更换目录资料」搜索并查看候选歌名、歌手、专辑、封面与来源链接，采用后保存所选目录身份；可选择「保留来源资料，停止自动匹配」恢复来源显示。搜索与采用失败保留原资料，未保存草稿先按既有机制处理。目录接口不可用时继续使用来源封面；没有封面则显示占位。目录记录及人工封面保护随歌曲快照备份，旧版 1 快照仍可导入。

新来源保存前由服务读取确切元信息，B站必须取得 BV＋cid。已有确切来源直接复用其歌曲和版本，收藏、加入歌单不再依赖远端元信息，也不隐式刷新可用性；没有 cid 的 BV 仍需先解析，来源关闭、修订冲突与取消仍受检查。不按相同标题合并。首个版本成为默认，备用版本保留已有默认；搜索歌曲其他版本时，用户明确将结果添加到该歌曲。

歌单与收藏中的单版本歌曲直接点播，不常驻重复的默认来源说明；多版本歌曲显示版本数量入口，固定成员保留固定版本标记。桌面「更多操作」使用浮动菜单，提供歌曲与版本、排序、移除和加入歌单；固定版本在歌曲弹窗按具体歌单记录设置，重复成员可分别选择。手机沿用原有行内展开。无永久版本选择的歌曲显示「播放时自动匹配」。后台约每 5 秒检查轻量修订号，有变化才读取完整资料；读取失败保留当前内容并在歌单页提供重试。

当前音轨或来源菜单提供「归入歌曲」：填写歌名、歌手与可选版本名，一次保存歌曲、首个版本和收藏；也可选择已有歌曲追加版本，保留已有默认。已归属其他歌曲的来源先预览归组影响。桌面「加入已有歌曲」与合并、移动版本的目标列表和歌曲管理一致，只列出当前收藏或任一歌单中的歌曲；不预选已移出这些范围的历史归属。弹窗打开期间目标失去全部收藏和歌单归属时，清除目标选择与影响预览，重新选择后才能提交。桌面歌曲窗口提供「播放版本／歌曲资料」，版本列表选择仅浏览详情，试听直接播放；歌名、歌手、多个版本的名称／类别／演唱者、歌曲默认与本条歌单固定版本统一「保存更改」。有草稿时离开或进行独立写入需选择保存、放弃或继续编辑；并发变化保留草稿并展示最新值供核对。搜索添加版本时点击结果右侧「＋」，关闭搜索返回原窗口并定位新增版本，修改关键词继续保持目标歌曲。手机保留现有歌曲窗口。保存归组不重新加载当前声音。

需要整理资料时，在「更多操作 → 歌曲与版本」中按需打开「查看整理建议」。应用只使用已经保存的目录和来源标题生成少量候选，可查看依据、勾选歌名／歌手后人工采用；采用的字段设为人工保护，并标记已整理。生成与查看不修改资料，不增加取源请求，播放与收藏不等待整理。已人工修改的字段不会被建议覆盖；不同解释分别显示，合集、串烧和同名歌曲不自动归组或合并。并发资料变化或建议到期时须重新生成，失败仅在该面板重试。

已有默认／固定版本由浏览器本地索引选出确切来源，纯点播不等待资料库 HTTP 查询；已存确切版本使用来源事实直接准备音轨，省去独立的元信息预查，音轨准备仍实时检查来源。未解析来源继续先取得确切元信息。公开搜索、分区识别与元信息读取不附带 B站登录凭据；需要账号权限的取流与同步仍使用各自账号上下文。

批量来源在当前页面预览，支持来源列表、公开歌单与作者合集；最多 1000 项／100 页，每次明确提交最多 500 项。失败项单列，可用项保留；未读完、达到上限或存在失败时，须确认仅添加本次已选可用项。提交时服务核对来源身份与已有归属，仅为新来源或没有 cid 的 BV 取得元信息，任一失败则整体不写入。歌单重复策略支持允许、跳过和整体拒绝。

桌面歌单页的「歌曲管理」展示当前收藏或任一歌单中的歌曲，支持歌名／歌手搜索，以及失效和待检查筛选；列表与计数随最新收藏和歌单更新，同歌重复成员只展示一首。取消收藏且移出所有歌单后不再列出，仍在任一歌单时继续显示；重新收藏或加入歌单后重新显示，底层歌曲资料与版本保留。日常编辑从歌曲弹窗完成，合并重复歌曲、转移放错的版本和删除各有独立任务入口，不使用通用维护操作下拉框。可勾选最多 20 个版本检查来源，只清理已确认不存在的版本；网络／账号／限流问题列为暂时无法确认。合并、移动、删除和清理先展示对象、受影响歌单、默认与固定选择、同步关联及 B站收藏夹视频移除影响，再按修订提交。合并保留目标歌曲资料与歌单重复次数；移动／删除版本取消受影响的默认和固定选择，不自行指定替代版本。手机保留原有「资料库维护」。

设置与歌单页打开同一新备份面板。仅接受 slowtune-library 版本 1，最多 64 MiB；导入先校验并预览，支持追加／替换，替换需确认移除范围。保存人工资料、版本、收藏及成员身份／顺序、默认和固定版本；不含音视频、凭据、关注、推荐偏好、来源设置、远端同步权限或浏览器队列。旧格式不转换。

## B站账号与收藏夹同步

应用提供 B站扫码登录、检查状态、更换账号与退出。二维码在浏览器本地生成。账号由同一服务共享；退出当前浏览器会话与退出B站账号是两个操作。凭据当前通过 Windows 当前用户 DPAPI 保存，不能据此声称其他系统已具备同样的持久登录能力。

设置内可读取账号收藏夹、预览并确认关联、逐成员选择 B站版本、暂停／恢复、立即同步及解除关联，也可明确新建公开或私密收藏夹。同步按账号、关联、具体成员和 BV 保存映射；同 BV 多成员／分 P 在远端只投影一个视频。新增未映射成员需重新确认，改默认或增加备用不改已有映射。远端删除解除相应同步贡献，独立本地成员保留且不会自动重新生成映射。解除关联保留两端资料。

发送远端请求前先持久保存意图，并在重试时重读当前映射和账号代次。新建结果不确定时只核对结果，不盲目重建。导入备份会使相关关联等待重新核对，备份不恢复远端删除权限。完整规则见[架构与数据](../开发/架构与数据.md#写入与并发)。

## 应用关注与评论

应用关注名单保存在本服务，支持从歌曲或作者链接查看作者、关注／取消关注、浏览合集与投稿，以及最近更新。该操作不等同于修改B站平台关注关系。来源分页、失败警告和可用条目分别呈现；关闭 YouTube 后禁用对应远端读取。

最近更新在服务端生成按发布时间排列的去重快照，支持按页码和每页条数直接读取；同一快照翻页不重新读取全部作者。快照绑定访问会话、关注名单修订与来源，闲置约 10 分钟、被缓存淘汰或服务重启后需重新获取；失败保留当前内容。总量是本批近期投稿的数量，不是作者历史投稿总量。B站投稿与合集内容可按上游总量直接定位页面；每页最多读取所需的少量来源页。

评论功能仅供读取，支持热门／最新、评论与回复分页。B站各分 P 使用同一视频评论区。切歌、切排序、关闭面板与取消会作废旧读取；没有评论发布、回复或点赞写入入口。

## 设置与 YouTube 开关

桌面设置分组为外观、启动与访问、音乐来源、B站账号、推荐偏好、诊断与数据、关于与声明。手机从“我的”的账号摘要与分组入口进入独立设置子页，顶部只显示返回与当前标题，保留迷你播放器；返回、前进及从播放页返回恢复对应子页，当前页面会话内保留编辑草稿。明暗模式与四套主题配色直接在外观页选择并即时生效；来源关闭后的歌曲展示方式通过底部选择面板修改，欢迎页编辑从外观页单独进入。

外观内的欢迎页支持内置／自定义／纯色、电脑和手机独立构图、背景遮罩、电脑面板位置、主题预览及图片与设置的独立备份，保存于服务。「启动与访问」可切换访问验证、校验并修改访问码。默认开启验证，关闭后欢迎页至少展示约 1.5 秒，同时准备数据，服务状态与来源握手就绪后自动进入，歌单收藏继续在后台加载。详细流程与恢复方式见[欢迎页与访问设置](../产品/启动与访问.md)。

YouTube 默认关闭，关闭资料显示方式默认变灰，也可选正常显示或隐藏。开启后才检查显式配置的 `yt-dlp` 及 Node JS runtime；目前目录由 `youtubei.js` 接入，播放由外部取源工具解析。没有 YouTube 账号登录入口。

来源设置保存在服务并以修订控制写入，通过 SSE 与重新读取反映到各页面。关闭时取消对应任务和租约；不能用迟到结果重新恢复已取消的 YouTube 搜索或播放。

推荐偏好支持关键词偏好／排除、排列方式、匹配字段、高级条件与完整配置／旧版兼容。预览后保存；编辑或切换导致预览失效时需重做预览。偏好作用于已获取候选，不代表按词扫描全平台或分析音频。

外观包含跟随系统／白天／黑夜，以及暖纸炭黑、经典薄荷、晴樱粉、珊瑚红四套配色。四款共用暖纸炭黑的背景、卡片、正文和边框，后三款通过主要按钮、进度条、收藏、焦点与选中态体现主题色；旧蓝色和紫色偏好分别对应晴樱粉和珊瑚红。跟随系统时，系统深色或本机时间 18:00–次日 06:00 使用黑夜，其余时间使用白天；手动选择不受时间影响。模式与配色保存在各自浏览器，同源页面可响应存储变化。统一布局见[界面规范](../开发/界面规范.md)。

源码：[设置页](../../src/SettingsPage.tsx)、[来源状态](../../server/source-settings.ts)、[YouTube 运行时](../../server/youtube-runtime.ts)、[推荐偏好](../../src/RecommendationSettings.tsx)、[主题](../../src/theme.ts)。

## 当前能力边界

当前没有原生安装客户端、独立手机运行时、通用跨设备云同步、音视频下载、完整离线曲库、用户自行注册的多账号系统或 YouTube 个性化登录。

第三方内部接口和平台内容是否可用取决于真实网络、地区、账号与上游响应。代码实现、受控验证和设备验收分别确认。设备与发行限制见[当前限制](当前限制.md)，检查要求见[验证规范](../开发/验证规范.md)。
