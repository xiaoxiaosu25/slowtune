# 当前限制

慢听当前为 Windows 桌面开发预览版。当前功能见[产品功能](产品功能.md)，安装与数据维护见[运行维护](../运维/运行维护.md)。

- 当前主要维护 Windows 桌面版；移动网页保留既有功能，暂停开发。其他操作系统与独立手机客户端没有完成支持与验收。
- B站、YouTube、网易云和 LRCLIB 的非官方接入或外部服务受接口、账号权限、地区和网络影响。
- YouTube 默认关闭，取源工具需要自行配置；软件不自动下载 yt-dlp，也不提供 YouTube 账号登录。
- 当前没有程序签名、安装器或自动更新。源码修改后需要重新构建；免安装版更新时须保留自己的 data。
- 歌单 JSON 只备份其格式中的歌曲资料；完整恢复还需要退出后备份整个 data。换机器或 Windows 用户后，B站账号可能需要重新登录。
- 悬浮歌词的多显示器、缩放、全屏应用遮挡、实体媒体键、休眠唤醒和长期连续播放仍需更多实际设备验证。自动化检查通过不代表所有设备场景均已验证。
- 尚未完成干净 Windows 环境与跨用户恢复的完整发行验收，不将开发机运行结果表述为新机器安装保证。

反馈问题时请提供版本、环境和复现步骤，方法见[贡献指南](../../CONTRIBUTING.md)。已确认的公开问题与改进通过 GitHub Issues 跟踪。
