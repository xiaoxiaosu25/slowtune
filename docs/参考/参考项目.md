## 当前采用的方向

保留现有 React 网页、Node／Hono 服务、HTTP 媒体链路和产品资料模型，以 Electron 增加 Windows 桌面入口。Android／iOS 当前使用响应式网页，独立客户端需另验取源、凭据、存储、后台与锁屏能力。详细执行要求见[桌面应用方案](../计划/桌面应用方案.md)。

## 文档与技术规范参考

- [Diátaxis](https://diataxis.fr/)：按读者需要区分操作、参考与解释，用于组织正文职责；目录按本项目的产品、开发、运维、计划、参考落地。
- [Hono OpenAPI 示例](https://hono.dev/examples/zod-openapi)：完整接口文档生成需要明确 schema；本项目当前采用路由事实生成与人工语义说明，完整契约建设仍是后续任务。
- [Electron 进程模型](https://www.electronjs.org/docs/latest/tutorial/process-model)与[IPC](https://www.electronjs.org/docs/latest/tutorial/ipc)：限定桌面宿主与渲染器的能力边界。
