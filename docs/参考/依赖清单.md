## 依赖职责与材料

- React、React DOM、图标与二维码用于界面；Hono 和 Node 适配器提供 HTTP 服务；YouTube.js 提供 YouTube 目录读取。
- `@applemusic-like-lyrics/core@0.6.0` 仅用于桌面沉浸歌词，按需加载并用 Shadow DOM 隔离样式；其 AGPL 许可、上游源码归档和当前构建对应源码下载见[第三方声明](../../第三方声明.md)。普通底部歌词与手机原实现保持独立。
- 自有公共包的边界见[架构与数据](../开发/架构与数据.md#公共包边界)。只列锁文件当前使用的制品，不把 vendor 内保留的其他文件视为正在使用。
- TypeScript 和 Vite 用于构建，Playwright 用于浏览器验证；Markdown 解析和章节标识依赖仅供文档工具使用。
- 第三方直接与传递运行依赖、字体的完整许可正文由现有[材料生成脚本](../../scripts/generate-notices.mjs)维护于产品随附材料，详见[第三方声明](../../第三方声明.md)。本页不复制许可全文。
- 外部 Node runtime、yt-dlp、Python／EJS 等宿主工具不属于 npm 依赖清单，也未随当前服务包捆绑；配置与边界见[运行维护](../运维/运行维护.md#来源工具与账号)。
