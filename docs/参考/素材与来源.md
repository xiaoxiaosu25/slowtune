# 素材与来源

## 当前视觉素材

| 素材 | 使用与维护 |
| --- | --- |
| [黑红唱片材质](../../public/assets/vinyl-black-red.webp) | 1254×1254 RGBA WebP，约 210 KiB；用于唱片盘面和音环中央红色纸质标签 |
| 本地字体 | `public/fonts/` 的 Noto Sans SC、Noto Serif SC 子集及所附 SIL OFL；界面字体以 [styles.css](../../src/styles.css) 为准 |
| 歌曲封面 | 桌面歌曲可采用网易云目录返回的专辑／单曲封面，保留目录身份与来源链接；未匹配时及手机仍使用来源元信息，未知时显示占位，不伪造图片 |
| 图标 | 使用项目已安装的 Phosphor 图标库，保持现有语义和可访问名称 |

唱片材质使用 ImageGen 生成，透明背景，炭黑盘面 `#19191B` 与酒红标签 `#A92E32`，不含平台标识、文字或歌曲封面。[PlayingArtwork.tsx](../../src/PlayingArtwork.tsx)负责慢听字标、转速标记、细线、轴心、旋转与固定高光。唱片和音环不叠加歌曲封面，材质配色与页面主题分别维护；显示比例见[界面规范](../开发/界面规范.md)。

## 来源与参考

平台内容、实际参考范围和账号数据声明统一见[第三方声明](../../第三方声明.md)。功能参考、复制的源码和运行依赖是不同关系，按实际使用记录，不把阅读过的项目列成运行依赖或源码授权。

YouTube 目录使用 `youtubei.js`，播放解析使用宿主显式提供的 yt-dlp；B站来源适配与远端收藏操作见对应服务模块。平台接入范围以当前实现为准。

歌词由产品自有适配器请求网易云网页接口与 [LRCLIB API](https://lrclib.net/docs)，或由用户导入；保留提供方及歌曲 ID 并提供来源链接。桌面沉浸歌词使用固定版本的 `@applemusic-like-lyrics/core`，上游对应源码保存在 `legal/upstream/`，构建时生成随附源码材料；其他歌词视图使用产品自有实现。不引入社区网易云 API 服务。功能参考包括 [BBPlayer](https://github.com/bbplayer-app/BBPlayer) 的多源候选／人工选择／偏移流程，属于功能参考而非运行依赖。

## 依赖与随附许可

- 安装版本与许可范围对照 [package.json](../../package.json)、[package-lock.json](../../package-lock.json)。
- 自有公共包固定制品由 [vendor/provenance.json](../../vendor/provenance.json)记录来源，确切版本源码与重建方式见 [vendor/README.md](../../vendor/README.md)；不手改 tarball、源码快照或 `node_modules`。
- [generate-notices.mjs](../../scripts/generate-notices.mjs)在构建时核对版本并生成 `public/legal/notices.json` 与 `public/legal/THIRD-PARTY-NOTICES.txt`，由网页构建带入交付。
- `legal/upstream/` 保存需要补齐的固定上游许可原文及来源记录。原文、文件名和版权声明保持完整。

素材或依赖变化时同步核对来源与随附许可；构建生成的清单通过脚本更新。只改文档不代表已生成或部署新的产品构建。
