# 素材与来源

## 当前视觉素材

| 素材 | 用途 |
| --- | --- |
| [唱片材质](../../public/assets/vinyl-black-red.webp) | 1254×1254 RGBA WebP，约 210 KiB，唱片及音环中央标签 |
| `public/fonts/` | Noto Sans SC／Noto Serif SC 子集及 SIL OFL |
| 歌曲封面 | 目录或来源返回的实际图片，缺图使用占位 |
| 图标 | 已安装的 Phosphor 图标库 |

唱片由 ImageGen 生成，透明背景、炭黑 `#19191B` 与酒红 `#A92E32`。[PlayingArtwork.tsx](../../src/PlayingArtwork.tsx)绘制字标、细线、轴心、旋转及高光；唱片和音环不叠加歌曲封面。规格见[界面规范](../开发/界面规范.md)。

## 来源与参考

YouTube 目录使用 `youtubei.js`，播放使用宿主提供的 yt-dlp；B站由固定来源包和产品账号／收藏模块接入。

歌词来自产品适配的网易云接口、LRCLIB 或用户导入；沉浸渲染使用固定 AMLL，其他视图由产品实现。平台权利与参考致谢统一见[第三方声明](../../第三方声明.md)。
