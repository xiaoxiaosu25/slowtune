## 阅读与维护约定

- 产品说明回答当前能做什么；开发说明回答如何实现与调用；计划回答接下来做什么。技术细节只在其权威文档维护，其他位置使用链接。
- 本地文档链接使用相对路径。源码链接仅适用于源码工作区；服务交付包不含完整源码、开发脚本或测试，阅读使用与运行步骤无需这些文件。
- 路由、依赖和 npm 命令由 `npm run docs:generate` 更新；`npm run docs:check` 只读检查生成内容、接口覆盖、导航和本地链接，构建前必须通过。
- 生成清单不自动证明真实平台或实体设备可用。验证范围与方法见验证规范，待验收事项进入执行计划。
