## 维护方式

产品文档写操作，开发文档写机制、契约、界面规格和验证方法，运维文档写运行步骤，参考文档写依赖与素材来源。每个主题在对应正文维护，其他页面链接引用；具体规则见[开发约定](开发/开发约定.md#文档结构与命名)。公开正文描述当前行为，计划在独立维护资料仓库保存；历史变化查 Git 和 Releases。

`npm run docs:generate` 更新接口路由、依赖与版本、npm 命令三个生成区块，具体范围见[自动生成与检查](开发/开发约定.md#自动生成与检查)。README 下载链接与 vendor 包／源码表随发行或依赖更新人工核对。`npm run docs:check` 检查生成内容、接口覆盖、导航和本地链接。

源码链接适用于源码工作区，交付文档的开发引用指向对应版本源码。
