## 维护方式

每个主题只在对应正文完整说明，其他页面链接引用。正文描述当前规则，方案只列剩余工作；历史变化查 Git 和 Releases。

版本、依赖、命令及路由清单由 `npm run docs:generate` 更新，`npm run docs:check` 检查生成内容、接口覆盖、导航和本地链接。源码链接仅适用于源码工作区，交付文档的开发引用指向对应版本源码。
