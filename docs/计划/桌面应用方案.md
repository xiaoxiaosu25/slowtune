# 桌面应用方案

Windows 桌面版是独立的个人音乐应用：双击、欢迎页、自动进入。当前为开发预览版，移动端开发冻结。

## 三端与两种运行形态

| 使用端 | 运行形态 | 资料归属 |
| --- | --- | --- |
| PC 网页 | 服务版 | 服务配置指定的实例 |
| 移动网页 | 服务版，冻结开发 | 与同服务的 PC 网页共享 |
| Windows 桌面 | 独立桌面版 | 程序旁 data，不依赖服务版 |

Electron、React、Node／Hono 继续复用业务、HTTP／SSE、播放器和 SQLite；不全面改写 IPC 或来源能力。内部本机服务仅监听回环地址，由宿主创建访问会话和管理启停，用户不配置端口或访问码。

## 启动与界面

源码目录的 `一键启动.cmd` 和 `npm run desktop` 直接打开已有桌面构建；重复点击唤起原窗口，不重建或停止进程。`npm run desktop:build` 仅构建，`npm run desktop:restart` 有序停止本桌面、重建并打开。构建失败不启动旧版本，未知进程不强杀。服务版实例目录的入口单独启动服务版。

同一主窗口先显示本地启动页，再载入业务页面完成资料准备；保留上次主题、欢迎图和构图，突出慢听标识及底部加载状态。启动页完整呈现后至少停留两秒，准备过程同时进行，耗时超过两秒时就绪即进入，播放器以 250 毫秒淡入。失败时保留窗口并提供重试、打开日志和退出；已有歌单可在断网时读取，来源内容显示各自失败与重试。

桌面设置移除访问码、配置切换和浏览器退出，增加“本地资料”。保留最小化播放、关窗退出、桌面歌词、主题、歌单备份和可选 B站账号。悬浮歌词仍消费唯一播放器的实际时钟与真实歌词，沙箱、上下文隔离和导航约束保留。浏览器和移动端保持原访问与存储行为。

“关于与声明”“音乐来源”“B站账号”和“运行信息”按独立桌面说明资料与账号归属；退出应用保留B站登录，退出B站账号才删除本应用凭据。“运行信息”提供显式复制入口，只复制实际取得的应用／运行时版本、来源开关与工具状态、资源计数及白名单错误分类。缺失字段为未知，刷新失败保留上次信息并标明失败；不复制原始错误、日志、账号身份、Cookie、访问码、控制密钥、媒体地址或私人路径，不上传、不引入遥测。

## 本地资料与实例边界

源码桌面以项目根 data 为资料根；免安装版以 EXE 同级 data 为根。`MUSIC_APP_DESKTOP_DATA` 只用于显式隔离运行与测试。路径集中解析，不依赖当前终端目录；资料根不可写或文件损坏时明确失败，不切到空库。

| data 下的位置 | 职责 |
| --- | --- |
| instance/config.local.json | 自动生成的桌面内部配置，不接受服务版配置继承 |
| library/ | 当前 SQLite 资料、设置、欢迎图和歌词 |
| preferences.json | 端口无关的队列、主题等桌面偏好 |
| desktop-state.json | 窗口及桌面歌词偏好 |
| profile/ | Electron 独立浏览器资料 |
| runtime/ | 本桌面运行记录、控制状态与当前用户加密的账号凭据 |
| cache/、logs/ | 可再生成 HTTP 缓存与排障日志 |
| backups/initial/ | 首次资料接入前的完整备份 |

data 不进入 Git，不属于构建、测试或历史产物清理范围。升级保留 data；完整备份在退出后复制整个目录，现有歌单 JSON 备份格式不扩展。换电脑或 Windows 用户后，账号凭据可能需要重新登录。

完整 data 恢复已通过同一 Windows 用户下的隔离验证：用当前格式合成资料正常关窗并等待桌面和服务退出，复制整个 data 到另一可写的中文／空格目录，再启动、关闭、重开。六个 SQLite 库均通过完整性及外键检查，全部表内容一致；歌曲、多个版本与默认／固定关系、歌单、收藏、同步关联／映射与待处理意图、关注、来源／搜索／推荐设置、歌词及偏移、欢迎图与构图、队列、主题、窗口及悬浮歌词偏好均保留。只验证合成 DPAPI 凭据在同用户下可读，服务上游请求被阻断，不执行真实登录或远端收藏写入；不代表跨用户／跨机器账号可用。

副本启动使用副本内相对资料路径；端口占用时选择新的本机端口，后续重开沿用可用端口，原资料和占用端口的监听器不变。死进程运行记录会被新记录替换；记录指向无关活进程时明确拒绝接管，正常退出删除本次服务及桌面运行记录。该验证不经过歌单 JSON 导入，也不增加历史开发格式迁移。

桌面只拥有自己的配置、端口和运行记录，不接管服务版。退出再核验配置归属、控制身份和目标 PID；启动途中关窗也等待启动结束并清理本实例。端口被占用时重新选择端口，偏好不随 Origin 丢失；已知拥有的运行中实例仍按归属处理。未完成 HTTP 连接不能阻止本桌面关闭，外部服务保持运行。

宿主仅增加白名单偏好读写、打开本地资料／日志目录、欢迎图缓存与退出桥接，移除配置切换。渲染器不能指定任意文件路径或进程操作；业务接口保护继续生效。

播放队列、渲染器界面偏好、窗口／悬浮歌词状态及欢迎图复用同一异步串行写入机制，分别写入各自临时文件、同步文件内容并原子替换；窗口状态按 200 毫秒合并，其他文件使用短合并窗口。落盘确认按修订顺序完成；读取和界面即时修改使用内存副本，写入期间的新修改继续按顺序保存。欢迎图 IPC 的 Promise 同样等待对应或较新修订落盘，失败会拒绝并显示本地设置保存提示，可重试。启动读取仍为低频同步操作，不据此宣称全部磁盘操作无阻塞。

`desktop-state.json` 仅在文件不存在时使用首次启动默认值；JSON 损坏、当前格式无效及权限／磁盘读取失败分别报告，未成功读取前不启动内部服务、不创建状态写入器。窗口事件、重试和退出均不能用默认值覆盖原文件。恢复入口可打开资料文件夹：先另行保留原文件，再恢复有效备份；或明确将原文件改名后重试，以重建窗口／歌词状态。缺省字段继续使用当前默认与边界规则，不增加历史开发格式迁移。

退出先等待启动结束并保存，再释放播放器并切到关闭状态页，随后再次保存、核验归属并停服，最后等待停止期间的新修改。释放失败或确认超时也明确失败，不当作成功继续。失败保留最后成功文件及内存最新值，并说明失败阶段。释放前保存失败时可在播放器重试保存后再退出；播放器已释放、释放尚未确认或进入停服阶段后失败，窗口切到恢复页并提供“重试保存并退出”，原播放页面卸载、浮窗隐藏，不显示可正常播放的页面。重试保留原服务归属及内存资料，不重新构造存储或重复释放已卸载的播放器。必要落盘或停服失败均阻止正常退出；强制结束进程或断电不属于正常退出保证。

## 现有资料的一次性接入

`npm run desktop:adopt` 读取原桌面实际选择的配置，确认停服后备份并复制当前格式 SQLite、设置、歌词、加密凭据与 Electron 偏好；不转换旧模型。复制后检查 SQLite、表数量并通过当前模型读取关键数量，再启用新目录。原资料保留，非空目标拒绝覆盖或合并，失败保留中间目录供检查，不静默进入空库。

桌面副本保留远端映射和待处理意图，但将已启用的同步关联暂停，通过已有“核对映射并恢复”重新启用；服务版原关联不变。接入工具属于维护入口，不在每次正常启动时重新寻找或合并旧资料。

## 剩余任务与完成条件

源码与受控回归覆盖资料归属、端口冲突、完整 data 恢复与重开、会话恢复、重复打开、显式重建、启动失败和进程释放。首发加固还覆盖桌面文案、原生剪贴板诊断复制与敏感字段排除、大偏好合并写入、写入中修改、失败重试及立即关窗保存。具体方法与结论边界见[验证规范](../开发/验证规范.md#windows-桌面验证)；这些检查不构成下列实机发布验收。

悬浮歌词置顶已修复并通过当前 Windows 的原生状态回归。最小独立 Electron（含脱离 Playwright 的直接启动）和产品原先都在默认 `floating` 层级返回非置顶；本机任务栏 HWND 本身也没有 `WS_EX_TOPMOST`。对照 [Electron 44.9 的 Windows 实现](https://github.com/electron/electron/blob/v44.9.0/shell/browser/native_window_views.cc#L1104)，默认层级会将窗口放到任务栏后，符合窗口被降到普通 Z 序的观察；不能据此将失败归结为测试方法。Windows 浮窗现显式使用 `pop-up-menu`，避开该任务栏重排分支；创建后隐藏、显示／再显示、锁定／解锁、主窗口焦点请求与最小化时，Electron 和同 HWND 的 Win32 置顶状态均通过，原最小化断言保留。焦点请求不代表实体前台已切换，自动化的系统前台窗口仍可属于宿主。不增加置顶轮询或外部进程修补；人工遮挡与实体鼠标行为仍按下表验收。

| 剩余验收 | 完成条件 |
| --- | --- |
| 手动升级与回退 | 用两份候选免安装程序验证退出、完整备份、替换程序并保留 data；版本与资源更新、资料及偏好保留、重复启动和关窗通过。失败可回到旧程序与匹配的备份副本；不让旧程序直接读取未经确认的新数据格式，不实现历史开发格式迁移 |
| 真实来源长期播放 | 对B站及显式启用的 YouTube 分别明确账号、版本与网络条件，连续播放至少 4 小时并跨越媒体地址有效期，覆盖自然接续、暂停恢复、切歌、最小化和网络中断重试；分别记录时间推进、非零信号、实际听感和错误，不以受控音频替代 |
| Windows 媒体键 | 实体键盘在前台、后台和最小化时验证播放／暂停、上一首／下一首；每次只执行一次，作用于唯一播放器，队列及系统媒体显示一致，退出后释放控制 |
| 悬浮歌词实机交互 | 在实际交互式 Windows 桌面，让普通窗口前置／最大化遮挡主窗口，并最小化慢听；目视核查歌词持续可见，实体鼠标验证拖动、贴靠、锁定穿透、悬停／托盘解锁。分别检查任务栏自动隐藏、多显示器和不同缩放；记录全屏应用覆盖行为。原生状态通过不替代此项 |
| 休眠与唤醒 | 实际 Windows 睡眠分别覆盖播放中、暂停中及唤醒后网络延迟；检查原暂停意图、过期地址恢复／明确重试、队列、歌词时钟、单播放器与退出清理；模拟 suspend／resume 仅用于回归 |
| 新机器交付 | 在无源码、无开发依赖及无预装 Node 的干净 Windows 环境完整解压；以普通用户在可写含空格／中文目录验证首次建库、重复启动、播放、关窗和资料重开，另用完整 data 副本验证跨机器／用户恢复及账号重新登录，记录架构与系统版本。YouTube 外部工具按现有方式另行配置，不能用本机源码启动代替 |

当前没有签名、安装器或自动更新；音视频下载、完整离线曲库及独立移动客户端不在当前桌面范围内。
