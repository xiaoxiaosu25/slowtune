# 开发约定

## 事实依据

1. 当前源码、类型、锁文件、配置和脚本定义是已实现行为的依据；用户最新决定是后续开发的依据。
2. 区分“已装配到产品”“已有独立模块”和“待实施”。代码存在、编译通过或受控测试通过，分别说明其范围，不写成已部署或真实来源已验收。
3. 当前规范描述实现，方案描述目标；发现差异时直接修订相关正文，不叠加互相冲突的版本说明。
4. 文档整理只调整文档和必要引用，不顺带改变业务行为。实际功能修改须完成对应验证。

## 开发期数据策略

移动端开发与修改暂停，直至用户明确下达恢复命令；权威协作准则见根目录 [AGENTS.md](../../AGENTS.md)。桌面改动必须隔离，保持既有移动端布局、样式与交互，不顺带进行响应式重构；既有移动端用例仅用于回归保护。

当前处于开发阶段，直接采用新数据模型，开发数据库通过明确的初始化入口重建。不实现历史数据迁移、旧客户端或旧接口桥接、旧备份导入、旧队列转换及长期双写。

新实现替换完成后，删除被取代的实现、测试、入口和无用依赖。保留事务、修订冲突、人工字段保护、来源身份和鉴权等当前功能正确性要求。正常的新格式备份恢复与同步失败重试仍须实现。

验证使用隔离数据库、端口和浏览器上下文。私人配置、凭据、日常实例及真实远端操作与开发验证分别处理；重建脚本只操作其已校验的明确目标。

## 开发产物管理

- 服务版日常实例位于 instances/slowtune；独立桌面资料在项目根或 EXE 同级 data，均不属于构建、测试或源码清理范围。
- 桌面开发完成后仅保留路径声明选定的当前构建；Studio 为 `studio/local/build/slowtune/desktop`，未声明路径的独立源码使用自身 `local/desktop-build`。隔离测试目录、截图、日志、历史构建、打包中间目录及旧分发包在验证完成后清除，不建立归档副本。
- `local/`、`artifacts/`、`test-results/` 与 `dist/` 不加入 Git；源码、有效测试、当前文档和必需的许可材料继续跟踪。
- `vendor/` 只保留包清单及锁文件实际引用的制品，来源记录只维护当前依赖。依赖替换时同时移除旧制品和失效的一次性脚本。
- 服务端开发临时生成的根目录 `dist/` 在交付桌面构建后清除。桌面输出通过 `scripts/workspace-paths.mjs` 统一解析，不保留第二份桌面构建。

## 文档结构与命名

- 根目录 [README](../../README.md)用于公开首页与桌面快速开始，[项目说明](../../项目说明.md)维护工程运行形态与 Studio 开发入口，[第三方声明](../../第三方声明.md)维护依赖和内容来源；公开协作规则见[开源与协作](开源与协作.md)。其余项目文档放在 `docs/`，按产品、开发、运维、计划、参考分类，文件名使用清晰的中文名称。
- [文档导航](../文档导航.md)是统一入口，列出全部项目文档及用途。每个主题只保留一份权威说明，不建立归档目录或阶段记录副本；历史版本通过 Git 查询。
- 当前功能、实现与操作说明各归对应分类；剩余任务维护于[执行总览](../计划/执行总览.md)及详细方案，完成后移入相应正文并删除待办项。
- 删除过时内容，直接更新为最新决定。测试数量、截图和部署状态不得在多个页面重复累积；有效验证说明保留范围与限制。
- 项目文档的本地引用使用相对链接；源码、配置键、协议、第三方制品和许可原文继续使用其真实名称，不为中文命名修改运行契约。
- 不把访问码、Cookie、控制密钥、签名媒体地址、运行 PID 或机器私人路径写入规范。配置示例明确标为示例。

## 自动生成与检查

`npm run docs:generate` 从当前路由声明及挂载关系、锁定依赖和 npm 脚本更新指定区块。生成区块以 `generated` 注释界定，不手改，不加入时间戳、私人路径或运行状态。接口含义、字段约束、架构原因、产品行为和计划仍由人工核对维护。

`npm run docs:check` 只读比较生成结果，并检查导航、本地链接、Markdown 章节锚点和接口说明覆盖；构建首先执行该检查。新增接口必须同时补充接口说明中的契约表，至少包括方法、路径、请求和响应；失效接口说明也必须移除。未支持的动态路由声明应扩展提取器，不能静默跳过。

依赖升级时先更新包清单与锁文件、安装依赖、维护实际使用的 vendor 来源记录，再生成文档。第三方许可继续由既有材料脚本生成，不在文档工具中复制一套许可逻辑。生成与检查只解析文件，不启动业务服务、不读取私人配置，也不执行接口示例或远端操作。

本地链接检查不联网验证上游可用性。源码工作区检查全部本地引用；服务交付检查保留文档导航与文档间链接，源码引用按导航声明仅适用于工作区。

## 修改时同步核对

| 变更 | 对应文档 |
| --- | --- |
| 页面、导航、播放与操作范围 | 产品功能、界面规范、验证规范 |
| 路由、字段、鉴权和错误 | 接口说明、架构与数据 |
| 数据、修订、备份与初始化 | 架构与数据、运行维护、歌曲资料库方案 |
| 依赖、启动、构建与交付 | 项目说明、运行维护、第三方声明 |
| 素材和来源 | 素材与来源、第三方声明 |
| 文件移动或改名 | 文档导航、全部引用、交付脚本 |

纯文档修改检查文件名、本地链接、章节锚点、源码对应和差异格式；功能修改按受影响范围运行测试。完整构建、受控浏览器、真实来源和实体设备分别记录结论，互不替代。
