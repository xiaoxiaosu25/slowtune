分发修改版本时保留版权与许可、说明修改并提供对应源码；网络服务义务以许可原文为准。不增加限制个人／商业使用的附加条件。内容来源见[第三方声明](../../第三方声明.md)。

## 公共包及对应源码

三个 `@studio/*` 包通过 `vendor/` 的固定 tarball 安装，对应版本源码随仓库提供，重建见 [vendor/README](../../vendor/README.md)。源码补丁由维护者合入正式包并生成新版本。

升级同时更新依赖、锁文件、安装包、对应源码、许可及来源记录，再生成文档。只整理文档不升级依赖，不使用其他版本源码代替当前制品源码。

当前来源包可选 `youtubei.js` peer 为 18.1.0，产品采用 18.2.0；根包以 `overrides` 引用自身依赖保持安装一致，包声明修正后移除覆盖。

构建的 `/legal/desktop-lyrics-source.tar.gz` 提供应用源码、构建脚本、锁文件、固定包及上游材料。[public-source.mjs](../../scripts/public-source.mjs)统一选择公开输入，拒绝本地配置和运行资料；新增公开文档须更新清单。

## 自动依赖更新

Dependabot 每周检查 npm 与 GitHub Actions，React、React DOM 和类型包成组升级；生成材料与验证通过后合入并删除临时分支。固定公共包人工更新。

`@types/node` 保持 24 大版本，`@vitejs/plugin-react` 保持 5 大版本，分别匹配当前 Node 24 和 Vite 6。升级环境时同步调整 `.github/dependabot.yml` 的大版本限制。

## 仓库边界

- 产品仓库收录源码、测试、锁文件、示例、静态资源、公开文档和必要许可材料。
- 配置、凭据、数据库、data、日志、缓存、构建及分发包不提交。忽略规则不清理已跟踪内容；发现泄露先撤销凭据，再单独处理历史。
- 计划、工作区入口和机器维护资料放独立本地／私有仓库，不以暂不 push 隔离。
- 测试输出用脱敏 Actions 附件，程序和发行说明用 Releases；不在文档中保留执行流水。
- 软件与资料备份不包含第三方曲库或内容传播授权。

`node scripts/generate-notices.mjs` 生成许可及对应源码材料。`node scripts/export-source.mjs <新目录>` 导出公开输入和材料，目标须不存在；不含 Git 历史，不提交或上传，也不生成 EXE／ZIP。

## 开发范围

产品适配在本仓库，公共包修复按制品流程更新。维护 Windows 桌面和移动 Web；原生手机端另定范围，见[开发约定](开发约定.md)。

安全问题优先使用仓库私密漏洞报告；无私密渠道时只公开问题类别并请求渠道，不附利用细节或凭据。
