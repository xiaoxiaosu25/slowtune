# 界面规范

适用于当前 React 网页、桌面侧栏和手机导航。实现入口为 [styles.css](../../src/styles.css)、[theme.ts](../../src/theme.ts) 与已有组件；Electron 顶栏适配见 [desktop-chrome.css](../../src/desktop-chrome.css)。本文与代码不符时先核对当前实现。

## 视觉方向

以音乐内容、清晰层级和适当留白为主。当前有暖纸炭黑、经典薄荷、晴樱粉、珊瑚红四套配色，每套都有白天／黑夜版本；明暗可跟随系统。默认配色是暖纸炭黑，默认明暗跟随系统。四套配色共用暖纸炭黑的背景、面板、正文、说明和边框；仅主要操作与交互状态体现主题色。色彩不随导航变化，沉浸播放的封面环境色受全局主题遮罩约束。配色清单和色值分别以 `theme.ts`、`styles.css` 为准。

全站白天背景为 `#F3F0E9`、面板为 `#FFFCF7`，黑夜背景为 `#1B1916`、面板为 `#27231F`，切换配色不会改变这些基础色。不额外叠加声纹、水印或平台大图形，不在按钮、文字后铺装饰。歌单信息区不重复铺封面模糊图。发现页两／三／四列密度保持一致。

| 配色 | 白天主要操作 | 白天强调文字 | 黑夜主题色 |
| --- | --- | --- | --- |
| 暖纸炭黑 | 炭黑 `#252720` | 砖红 `#AC3E27` | 浅纸主要操作 `#F2ECE1`、暖红强调 `#EEA086` |
| 经典薄荷 | 鲜绿 `#31C27C` | 深绿 `#126D46` | `#43D99A` |
| 晴樱粉 | 明粉 `#FF6699` | 莓粉 `#B62758` | `#FF80AB` |
| 珊瑚红 | 珊瑚红 `#FA233B` | 深红 `#BE263C` | `#FF6377` |

后三款主要按钮的文字与图标统一使用 `#151515`；白天进度、焦点与小图标分别使用 `#168653`、`#D64178`、`#DE2944`。晴樱粉白天的小徽标使用 `#090909` 文字，珊瑚红黑夜的强调文字使用稍亮的 `#FF7385`，保证徽标与选中态文字对比度至少 4.5:1。局部选中底色以强调色混入面板，白天占 10%、黑夜占 14%。主题预览在各自明暗模式下计算相同变量；浏览器顶栏和首屏启动沿用共用背景。内部配色 ID 分别为 `paper`、`mint`、`ocean`、`plum`。

榜单的平台特色仅通过标签旁的 16px 同库小图标、选中标签的少量底色和前三名序号表达；`--platform-*` / `--chart-tone` 仅服务这些小范围细节。正文与主要操作继续共用全站语义色。

- 页面底 `--bg`，内容面板 `--surface`，分组底 `--surface-soft`，浮起元素 `--raised`，侧栏 `--sidebar`。
- 正文 `--text`，说明和作者 `--muted`，配色强调 `--accent` / `--on-accent`，强调文字 `--accent-text`。
- 主要实心按钮使用 `--primary` / `--on-primary`；暖纸炭黑沿用正文与面板色，后三款的播放、保存和确认使用各款主要操作色。强调文字另用 `--accent-text`，不要直接套用鲜亮按钮底色。
- 当前项 `--selected`，结构分隔 `--border`，列表细线 `--border-subtle`，表单边线 `--control-border`，错误与危险动作 `--danger`。
- 面板轻投影 `--shadow-sm`，对话框和浮层 `--shadow`，输入焦点辅助光圈 `--focus-ring`。
- 不在单页内重新定义一套主题色。来源保持真实名称，未知封面、未知时长与关闭的来源都明确显示状态。
- 选中、当前播放和提示状态不使用左侧装饰竖线、伪元素短线或单边 inset 阴影。导航、列表与队列用底色和文字强调状态；错误提示用整体边框和浅底色。面板之间的结构分隔线不属于状态装饰。

## 字体、间距与形状

统一使用本地 Noto Sans SC、Microsoft YaHei、sans-serif。正文 14px，次要信息 13px，元信息 12px，组标题 16–18px；页面标题 21–24px，歌单标题桌面 28px，沉浸歌曲标题随可用高度适配。

间距使用 4 / 8 / 12 / 16 / 24 / 32 / 48px 刻度。通用小圆角 8px，控件 12px，独立卡片与弹窗 18px；播放主键、头像和特定图标按钮保留圆形。进度、时长、数量使用等宽数字。桌面内容平铺，标题、留白与细分隔线承担分组；圆角底板仅用于控件、独立内容对象和浮层，不给列表、表单与其内部字段重复套底板。工具栏与列表至少间隔 16px，字段间隔 16px，分组间隔 24–32px。移动端保留现有容器规范。

## 按钮审查与选型

| 用途 | 组件／样式 | 规范 |
| --- | --- | --- |
| 立即播放、保存、确认 | `.btn.btn-primary` / `PlayAllButton` | 使用主要按钮语义色的实心样式；同一操作区突出一个主要动作 |
| 入队、加入歌单、改名、预览、同步 | `.btn.btn-secondary` | 中性浅底与细边线，选中用 `aria-pressed` |
| 取消、返回、轻量辅助 | `.btn.btn-ghost` | 弱化文字，悬停和键盘焦点仍可见 |
| 删除、解除关联 | `.btn.btn-danger` | 危险语义色；确认区先取消、后危险动作 |
| 收藏、更多、关闭、来源链接 | `.btn.btn-icon` | 可访问名称；仅图标的操作提供说明或悬浮标题 |
| 换批、刷新 | `RefreshButton` | 读取时保留宽度、禁用与忙碌状态；不新增重复入口 |
| 封面／列表、来源、评论排序 | `.segmented` / `CatalogViewToggle` | 同一轨道、同一高度；当前项有底色与文字强调 |
| 倍速、睡眠、队列 | `RateControl` / `.player-setting` | 共用辅助控件外观，打开态与开启态清楚可辨 |
| 歌曲名、封面、作者 | 现有歌曲组件 | 歌曲和封面可点播；作者可查看内容；长标题保留完整提示 |

桌面普通按钮 40px，紧凑工具条 36px，图标按钮 36px。手机普通、紧凑、栏目图标、说明入口与核心播放触控目标至少 44px；320px 不再把通用图标按钮缩到 40px。不要为每个入口再建独立尺寸。

禁用态明确区分且不响应动作；加载态保留操作语义。键盘焦点使用可见轮廓，不允许仅移除 outline。支持减少动态效果的系统偏好。

## 表单与弹窗

统一 `.field`、`.field-label`、`.input`、`.select`、`.textarea`、`.choice`。下拉框必须使用 `.select`，批量导入和同步关联也遵循同一规范。字段标签常驻，不能只依赖 placeholder。

简单的新建、改名、删除和链接弹窗桌面最大 480px，复杂歌曲操作与导入保留对应宽度。普通表单按字段分组，确认动作与取消对齐，危险操作使用独立语义。手机歌曲面板从底部展开，长内容在面板内滚动，操作区保持可达。

歌曲操作面板中的查看作者、关注、查看来源及适用的歌单操作直接展示，不使用“更多操作”折叠入口。

`Modal` 负责 Esc、焦点限制、背景滚动锁定和关闭后的焦点返回。需要首先输入的字段标记 `data-autofocus="true"`，在原生 dialog 打开后聚焦；不要只依赖 React 的挂载自动聚焦。

## 页面与内容

### 全局布局与播放条

- 普通页面共用最大 1600px、居中及响应式内边距。桌面展开队列时，先从应用可用区域扣除队列宽度，再按同一规则排列内容；不因队列打开而取消内容宽度上限。正在播放页继续使用专用布局。
- 队列初始关闭，仅由用户操作打开或关闭；发现、榜单、关注、歌单、设置和正在播放页切换时保留手动开关。跨越 1050px 断点仅切换侧栏／模态抽屉形态；刷新后关闭面板，已有播放队列内容继续恢复。桌面右侧队列背景和分隔线延伸到窗口底部，内部列表独立滚动，数量与清空操作固定在列表下方；按播放器样式和横向重叠情况为内部内容避让，不截短面板容器。
- 桌面底部播放器在“更多播放选项”中提供“悬浮播放岛／底部长条”单选，默认浮岛，选择立即生效并保存在当前浏览器，同源标签页同步。两种外壳共用同一内部组件和几何布局：浮岛最大宽 1280px、左右至少 16px、距底部 16px、高 88px、18px 圆角；长条背景铺满窗口并贴底，高 104px、平直边缘与顶部细分隔线，内部内容仍限宽居中。两种模式均保留 104px 页面占位，切换不重建媒体、不打断播放。左侧歌曲信息、中间播放与进度、右侧工具收拢排列，左右列等宽，播放主键在窗口中线；长标题省略并保留完整提示。1250px 以下倍速与定时仅在更多中显示，宽屏仅在底栏显示，避免重复。761–1050px 使用紧凑间距与短音量条；760px 及以下沿用全宽移动底栏和导航，保留宽屏样式偏好。
- 桌面睡眠面板顶部展示当前生效规则，下方保留可编辑草稿。草稿与运行规则不同时显示“修改尚未生效”并将提交按钮标为“应用设置”；快捷设置明确点击立即生效，重复点击同一选项也同步表单。定时错误不展示完成提示，允许取消；底栏和面板采用同一向上取整的剩余秒数。

### 导航与全局工具

- 导航：当前页有明确选中态；侧栏标志、收藏图块、歌单缩略图形成固定对齐。桌面侧栏背景和分隔线延伸到窗口底部，歌单区独立滚动并按需避让底部播放器；粘贴链接、明暗切换、设置三个图标固定在侧栏底部，不随歌单或页面滚动。桌面正在播放页移除左下角工具组，返回主界面后使用侧栏入口。桌面右上角只保留原生窗口操作，取消独立应用菜单。当前设置页齿轮使用强调色、浅底色和 `aria-current`。工具按钮提供可访问名称及悬浮提示，桌面点击区域沿用 40px 普通控件高度。手机维持右上角工具区、至少 44px 点击区域和搜索独占第二行的既有布局，手机导航同步提供 `aria-current`。
- Electron 桌面顶栏保留原生窗口按钮，控制区高度为 40px；顶栏与正文之间不显示底部分割线，搜索框和正文布局保持原有位置。普通浏览器与手机沿用原有顶栏样式。
- 独立桌面“本地资料”的备份按钮明确称“歌单 JSON 导入与导出”，完整 data 恢复另按退出后复制目录的说明操作。窗口／歌词状态读取失败的启动页提供重试及资料文件夹入口；退出中播放器已释放、释放未确认或进入停服阶段后失败，显示阶段与“重试保存并退出”，不保留可正常播放的页面。
- 桌面悬浮歌词只在启用且当前歌曲有实际歌词文字时显示；等待、加载、未匹配、失败、空白歌词和纯音乐时隐藏整个浮窗，不显示占位提示或残留鼠标拦截区域。有歌词后自动恢复，保留手动开关、锁定与位置；前奏和间奏不按当前句是否为空反复切换窗口，无时间轴的歌词显示实际文字。工具栏使用带可访问名称与提示的图标，快捷设置内可直接调整字号、文字颜色、高亮颜色、双行、翻译并重置位置；与设置页“桌面歌词”共用偏好。打开面板时临时向上扩展浮窗，关闭后恢复紧凑尺寸，保持歌词屏幕位置。锁定后只显示歌词并鼠标穿透，操作锁定时显示两秒的解锁说明；鼠标在歌词区域停留约 600 毫秒才显示 36px 小锁按钮，单击解锁，移出歌词和控件区域后淡出。隐藏入口不保留鼠标拦截区域，显示时仅按钮接收点击；锁定与解锁保持歌词位置。设置页和托盘保留可用键盘操作的解锁入口。独立桌面设置移除“启动与访问”和配置切换，增加“本地资料”；网页保留原访问设置。托盘仅保留打开慢听、桌面歌词开关、锁定后的解锁、重置位置及退出。
- 主题快捷切换沿用手动保存逻辑；“跟随系统”在系统／浏览器报告深色，或本机时间为 18:00–次日 06:00 时使用黑夜，其余时间使用白天；页面跨越时间边界及从后台恢复时自动更新。需要恢复自动跟随时重新选择该项。链接入口统一称“粘贴链接”，仍打开独立弹窗读取支持的视频、BV 号或公开歌单；搜索与链接读取分开保留。
### 发现与内容封面

- 发现：保留页首标题和来源选择，不增加大型横幅或已删除的重复操作。每栏最多展示 12 首，没有数量档位；推荐不足时保留占位。封面视图按栏目容器宽度显示两／三／四列：达到 600px 三列，达到 800px 四列，手机两列；大屏或收起队列时也不扩成五列以上。卡片填满各自列宽，作者与菜单在同一行对齐，分 P 标签不会挤乱相邻卡片。数量来自 [CatalogView.tsx](../../src/CatalogView.tsx)，列表范围见[产品规范](../产品/产品功能.md)。
- 封面：桌面内容缩略图统一为正方形，包含底部播放器、列表与队列、发现卡片、侧栏歌单、歌单主封面、关注合集，以及导入和歌曲操作弹窗；真实图片居中 cover 裁剪，缺图占位保持相同尺寸，不伪造来源封面。底部播放器沿用 48px 高度，761–1050px 为 40px，宽高相等。正在播放页保留用户选择的原图、方形或圆形展示，原图完整保留图片比例。装饰背景与内容封面分开处理。移动端保持既有封面比例和适配。
### 列表、分页与歌单

- 列表：各处保留现有信息排布、封面比例和信息密度；桌面发现栏目、榜单、歌单、关注列表和弹窗搜索结果直接铺在所属页面或浮层上，不再额外增加外围卡片。栏目之间用留白和细分隔线区分；队列保留侧栏形态。列表行共用 8px 圆角、细分隔线、悬停与当前项底色。已有序号使用 01、02…、12px 等宽数字和固定序号槽。普通列表的表头与数据行共用列定义，序号居中、文字左对齐、时长右对齐；手机保留原有外围卡片与堆叠元信息。榜单与队列不新增表头。
- 分页：复用 `Pagination` 与 `PagedList`，只在列表底部放一条紧凑栏，沿用 `.btn`、`.input`、`.select`、主题语义色和 12px 控件圆角。每页数量、首／上一页、页码输入／总页数、下一／尾页依次排列；首尾采用双箭头图标，不展开页码长条或额外跳转按钮。桌面高 36px，窄容器至少 44px；手机分两行，第一行数量与页码，第二行前后导航。使用列表容器宽度适配弹窗与展开队列的场景，避免底部播放器遮挡。榜单排名和分 P 编号保留原始序号，跨页勾选保留；未知总数显示省略号并解释尾页禁用原因。
- 榜单：平台标签支持左右键、Home、End，单一标签进入 Tab 顺序，面板名称保留榜单标题。前三名序号保留强调色和稍高字重，字号与其他序号一致。歌曲主体和直接播放按钮均调用现有匹配播放；独立搜索按钮用于选择其他版本。行内按钮桌面 36px、无描边，播放图标 16px；手机点击目标至少 44px。
- 歌单：封面、标题、数量与播放操作收进同一信息区，筛选与搜索为下一层。播放全部与批量加入歌单的范围保持现有行为。
- 桌面收藏／歌单封面为可聚焦按钮，悬停和键盘焦点显示相机与「更换封面」遮罩。弹窗复用 Modal，提供上传、从当前歌曲选择、恢复自动三种方式；选曲网格支持搜索和分页，右侧预览支持拖动、方向键及缩放，底部统一取消／保存。保存前保留原图；错误和冲突在弹窗内反馈，关闭返回封面焦点。主封面与桌面侧栏采用同一手动图片，手机保持既有路径。
- 桌面歌曲搜索：榜单搜索、自动匹配失败后的搜索及歌曲添加版本入口，使用“歌名 歌手”并在弹窗输入框显示实际关键词，允许直接编辑。手动提交保留输入原文；歌手缺失时只填歌名。移动端保留现有输入与查询行为。
- 歌曲行：单版本不常驻默认版本说明；多版本显示可打开歌曲窗口的数量入口，固定成员保留版本标记。桌面「更多操作」使用浮动菜单，提供歌曲与版本、加入歌单、排序与移除，不撑开歌曲行；加入歌单使用独立弹窗。手机沿用既有行内展开行为。资料读取失败只在歌单页显示重试，搜索与明确来源点播继续可用。
- 桌面歌曲窗口：最大 880px，固定头部与底部，正文滚动；「播放版本／歌曲资料」标签支持键盘切换。版本列表与详情分栏，紧凑桌面改为上下排列；歌曲默认、本条歌单记录固定与试听明确分开。歌曲和多个版本的资料统一「保存更改」，关闭或执行其他写入前处理草稿；并发变化逐字段展示最新内容和用户修改，核对后再保存。搜索添加版本暂时挂起原窗口，关闭搜索返回，草稿与上下文保留。
- 桌面歌曲管理：入口称「歌曲管理」，列出当前收藏或任一歌单中的歌曲，列表及计数跟随最新成员关系；取消收藏且移出所有歌单后隐藏，仍在任一歌单时保留，重新加入后恢复显示。「归入歌曲 → 加入已有歌曲」、合并与移动版本的目标列表共用此范围，失去全部当前归属的目标须清除选择和预览，并禁用提交；历史来源所属歌曲不自动预选。支持搜索和全部／存在失效版本／待检查筛选；移出列表的歌曲版本同时取消批量选择。进入歌曲后复用同一编辑窗口，返回保留筛选、选择、页码和位置。版本检查最多 20 个，清理只接受确认不存在的版本；合并、转移、删除按具体任务先预览影响，涉及 B站收藏夹移除时单独强调。移动端保留既有资料库维护界面。
- 整理建议：只在歌曲窗口按需打开，不给普通歌曲行增加常驻提示。候选逐字段显示当前值与建议，依据可展开；人工保护字段不提供覆盖选择。加载可取消，失败和并发变化在面板内提示并重新生成，收起不改变资料或播放。
### 正在播放与沉浸封面

- 播放：全站常驻播放条共用主题；沉浸页保留低饱和的局部封面环境色、队列／评论切换和高度适配。六种封面与音波展示共用固定方形槽，桌面上限 460px、单列上限 360px，并受可用高度约束；原图在槽内按自然比例居中。桌面两栏整体最大 1120px，详情上限 520px，可用内容宽度至少 1100px 时两栏间距 96px，其下双栏为 48px，750px 及以下改为单列；横向短屏使用 16px 紧凑间距。上一首／下一首与主播放键间距 8px，极窄屏 4px。原标题不按规则拆分，桌面标题区按实际一至两行占高，手机保留固定两行高度（短屏一行），点击或键盘打开完整标题弹窗，关闭后焦点返回标题。主播放区的状态、作者、时间、音量、模式说明与工具栏辅助文字至少 14px；顶部数量说明保持单行省略。主要播放键始终是视觉中心；播放模式说明跟随对应按钮，快退／快进使用图标加秒数，倍速／定时／队列共用轻量工具栏。恢复队列后首次进入播放页显示 3.5 秒提示，同次页面加载内不重复；常驻说明与快捷键收进更多播放选项。
- 沉浸展示未保存有效偏好时默认唱片，已有选择继续沿用；封面与音波淡入淡出 180ms，右侧控件不随样式移动。唱片为炭黑纹理盘面与酒红纸质标签，桌面普通和沉浸歌词两种模式中与圆形封面统一为展示槽的 80%、上限 360px；手机保持既有尺寸。标签约占直径 47.6%，带慢听字标、转速标记、细线与小轴心，不叠加歌曲封面；盘面与标签一起旋转，高光固定。方形上限 340px／展示槽的 76%，圆形居中保留留白与细边框。唱片和纯圆形均顺时针 24 秒一圈，暂停／缓冲保留角度；页面和音波继续跟随主题。
- 音波保留原有横向居中频谱柱，桌面 48 根、展示宽度不足 340px 时 32 根；所有柱体沿固定水平中线按真实频率上下展开，保留轻微的同步呼吸缩放，不增加波浪偏移，静音／暂停平滑回到低线。圆形音环作为独立样式保留，真实频谱左右镜像成 96／64 根细线，中心复用唱片的酒红纸质标签、完整印字、细线与轴心，保持静止，标签约占音环直径的 47%；展示槽小于 140px 时省略印字，保留红标签与轴心，静音／暂停收回细圆环；两种音波均不叠加封面。悬停和键盘聚焦时叠加“当前样式 · 点击切换”，触屏常驻；短屏使用侧面紧凑提示，显示槽保留至少 44px 触控区域。桌面播放时唱片与圆形封面始终按 24 秒一圈旋转，系统减少动态设置仅关闭展示过渡；暂停、缓冲、页面隐藏或被沉浸歌词覆盖时保留当前角度，恢复播放或显示后接续旋转。桌面实时频谱继续跟随音频，不显示减少动态提示或增加启用开关。手机既有减少动态行为保持原样。唱片材质来源见[视觉资产](../参考/素材与来源.md)。
- 正在播放页顶部左侧保留返回与播放信息，右侧共用全局图标工具区；窄屏播放数量说明单行省略，按钮保持完整。评论与队列仍通过播放器中的队列按钮打开侧面板，再使用面板内的“评论／队列”切换和关闭按钮。
- 桌面普通模式左侧按唱片 → 原图 → 方形 → 圆形 → 音波 → 音环循环。播放页去掉外围大圆角矩形，歌名按实际一至两行占高，歌手距歌名约 10px，歌手行仅展示歌手；下方灰色来源行通过点击、悬停或键盘聚焦展示原始完整标题、平台、上传者、分P及打开／复制操作，详情底部提供「选择版本」入口。主控制为模式 → 上一首 → 播放／暂停 → 下一首 → 收藏，模式仅图标并保留悬浮说明。歌名旁保留「词／更多」两个 44×44px 入口；「词」使用 24px 图标槽、20px／500 字重。倍速、定时、队列保留原图标、文字和交互，仅移除外围长胶囊。手机七种展示和布局保持既有表现，移动端开发暂停。
- 桌面「版本与歌词」采用非模态侧边面板，版本和歌词两个标签支持方向键、Home、End，播放器仍可操作。搜索结果可试听或保存，返回后保留搜索上下文；试听原位替换当前项，不改默认及收藏，准备失败保留播放。歌词候选先预览再采用；时间偏移即时预览、单独保存，关闭面板撤销未保存偏移。1100px 及以下打开管理面板时暂时收起普通页唱片，为播放控制留出空间；关闭后恢复。
- 桌面独立沉浸歌词仅在大于 760px 时启用，固定覆盖网页，隐藏原应用顶栏与内容并设为 inert。主体为封面／歌曲资料与歌词双栏，整体最大 1280px、两栏比例约 0.85:1.2、间距 48–112px；1050px 及以下使用 32px 间距和左右留白，保持桌面双栏。左栏展示槽上限 420px，复用六种桌面封面样式和点击切换，歌名与作者在封面下方居中，普通桌面模式的歌曲资料同样居中。标题最多两行并可展开，短屏收为一行。右侧歌词左对齐，默认 28px、600 字重、1.4 行高、24px 句间距，翻译 18px；播放选项与歌词设置可即时调整 20–40px 字号，当前浏览器保存并同步，手机不使用该偏好。当前句位于约 45% 高度，上下文按距离弱化并边缘渐隐。低饱和模糊封面色受主题遮罩约束，切歌交叉淡入淡出。
- 沉浸底栏采用最大 880px、88px 高、20px 圆角的居中悬浮卡片，距底部 16px，半透明面板底、细边框和轻投影；正文留出 120px 底部空间。进度／时间在卡片上沿，主播放键 48px 并保持窗口居中，其他图标按钮 40px，左右放模式／音量和队列／收藏／词／更多。「词」以强调色标记开启，提示及 aria-pressed 同步；左上角提供收起按钮，退出后焦点回原按钮。队列与评论使用覆盖抽屉。更多收纳倍速、定时、快进退、翻译和设置。正文支持键盘定位、手动浏览及 5 秒恢复，恢复按钮位于右侧歌词区下方；Esc 优先关闭上层，再退出沉浸。普通 LRC 只整句高亮；逐字动效只读取真实时间。减少动态效果时取消歌词缩放、模糊、平滑滚动；封面沿用桌面动态行为，失败仍能阅读及操作播放器。布局与样式见 [desktop-lyrics.css](../../src/desktop-lyrics.css)。
- 底部歌词默认开启、独立于左侧样式；播放页在内容下方显示当前句和下一句，浏览页在播放器上方显示紧凑版本，适配浮岛、长条、手机导航和安全区，并给正文、侧栏及队列留出空间。换句轻柔上移，有逐字时间时精准扫色，普通 LRC 按句时长估算，纯文本不模拟同步；翻译开启且存在时放在底部第二行。暂停与缓冲停止推进，减少动态效果时保留同步高亮、关闭平滑动画。前奏保留首句，未匹配、加载及纯音乐仅显示轻量提示。
- 开始播放即读取已选歌词或自动匹配，两处共用一次请求和实际播放时钟。切换来源取消旧请求，切换展示不重载音频。桌面沉浸歌词提供「更换歌词」「校准时间」，更多菜单提供「歌词管理」，均进入侧边面板；无时间轴时不提供校准，无歌词时提供查找与导入。手机保留原有「歌词设置」独立弹窗。歌词等独立列表滚动不关闭位置不变的播放菜单，祖先容器滚动或窗口尺寸变化时仍关闭。冲突时保留搜索、导入和偏移草稿，关闭管理界面放弃未保存校时预览。
- 手机开启底部歌词时，音量和快进退移入现有更多选项，为左侧阅读区留出高度；高度不超过 500px 时进一步收起状态徽标，将倍速、定时和队列移入更多，保留进度及主播放控制。关闭底部歌词后沿用原有响应式控制布局。
### 设置与反馈

- 设置：分组用同库图标；外观将明暗模式与四套配色分别选择，每套配色同时预览深浅外观。账号、来源、同步和推荐偏好复用面板、字段和反馈样式。
- Electron 设置中的诊断分组称“运行信息”，提供明确的“复制诊断信息”按钮及复制成功／失败反馈，最近读取时间与刷新失败状态分别呈现。未知版本或状态明确标记，不把来源工具可用当作实际播放通过；复制范围和隐私边界在按钮旁说明。浏览器保留“诊断与数据”。
- 桌面偏好或窗口状态保存失败时，在原生顶栏下方持续显示错误和“重试保存偏好”入口，保留内存修改；保存成功后清除。关闭窗口仍等待必要落盘，失败不静默退出。桌面资料、账号、备份和退出说明按独立 data 归属呈现，不影响浏览器及手机原文案。
- 空状态、失败与加载：保留真实原因与重试入口；不要用一组虚构内容掩盖未知或错误。
- 桌面歌曲管理、歌单封面和版本与歌词在首次打开时加载，等待期间可关闭。加载或渲染失败在原弹窗／侧面板提供重试和关闭；版本与歌词始终保持非模态，播放控制仍可操作。桌面页面渲染失败显示局部反馈，保留导航和当前音频，切换页面后恢复；重试可能需要重新填写该区域未保存的输入，已保存资料保留。

## 复核方式

在真实内容下检查长标题、分 P、混合来源、未知封面、当前项和空列表；检查桌面、平板与 320 / 390px 手机、四套配色的深浅主题、弹窗焦点与触控目标。复用适用的界面和播放器布局回归，方法见[验证规范](../开发/验证规范.md)。文档说明不代替当前构建的视觉验收。
