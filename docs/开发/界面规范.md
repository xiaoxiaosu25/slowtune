## 移动 Web 布局

760px 及以下使用 [MobileChrome](../../src/MobileChrome.tsx)、[MobileSettings](../../src/MobileSettings.tsx) 和 [MobilePlayer](../../src/MobilePlayer.tsx)，共用业务及唯一音频实例。

### 主导航与搜索

- 主顶栏 64px，左右留白 16px。底部为发现、音乐库、我的；发现内切换推荐、榜单、关注。
- 发现推荐的封面浏览采用一张横向重点封面和后续紧凑歌曲行；封面与列表均先展示六首，再展开到本批最多十二首。关注更新摘要先展示四首。展开入口标明剩余数量，收起后回到栏目开头。关注更新封面浏览采用两列 4:3 大图卡片，列表采用紧凑歌曲行。作者合集入口保留两列。播放与刷新直接可见，视图切换、批量加入歌单及添加关注等辅助操作进入底部面板。
- 手机的推荐、榜单、歌单与关注播放统一使用 48px 高的主题色胶囊，图标与文字并列。关注页在「最近更新」标题旁标明「播放本页」，顶部保留作者／更新、刷新和更多；总更新数与实际播放范围分开说明。推荐播放全部使用整批范围，折叠的展示数量不改变播放范围。
- 手机网易云榜单的类型选择位于标题，保留原生选择器与完整可访问名称；平台仍单独切换。更新时间摘要直接可见，完整来源时间、获取时间与原榜链接进入可展开的「榜单信息」。桌面保留现有类型选择和资料栏。
- 推荐、关注更新、作者投稿、搜索、歌单详情和榜单共用移动歌曲字号与间距变量：标题 15px／22px、元信息 12px／20px、常规间距 12px、紧凑列表 8px、操作区 48px。普通列表使用 56px 方形封面，360px 及以下使用 48px 封面和 6px 列间距，收藏与更多横向对齐；单版本歌曲行常规约 84px，有时间、分 P 或多版本时扩展。标题最多两行，作者与来源同行，发布时间独立成行。
- 浏览标题和封面都直接播放同一首内容，不增加全文确认步骤或展开箭头；完整来源标题与详情通过“更多”查看。已保存且来源身份明确的歌曲优先展示整理后的歌名，多 P 视频不能套用其中一首的歌名。移动端点播多 P 视频默认播放当前 P，不自动弹出整组选择；已记住的整组偏好继续生效，分 P 入口保留主动选择。
- 搜索为独立页面，返回键与 16px 输入同行，提交后收起键盘；共用迷你播放器，保留来源、筛选、错误、分页和一个固定的粘贴链接入口。
- 主导航、栏目及当前设置分组使用明确选中态和 `aria-current`。

### 设置与推荐偏好

设置子页仅显示返回和标题，保留迷你播放器。外观页直接选择明暗和四套主题，欢迎图单独进入编辑页。来源开关直接可用，关闭后的展示方式通过底部面板选择。推荐先展示关键词和顺序，搜索／自动选歌规则默认折叠，展开收起保留草稿。

### 历史、二级浏览与版本

- 搜索、歌单、设置、榜单、作者、合集和投稿进入浏览历史。返回先关闭上层操作，再恢复页面、分页、草稿和阅读位置；前进不重建已关闭弹层。
- 异步内容稳定后恢复滚动，用户滚动或新导航取消旧恢复；刷新保持当前页，恢复队列不自动播放。
- 作者与合集使用专用返回／搜索页头。版本页默认显示播放版本，当前播放与默认版本分别标记，切换状态就地反馈。
- 版本与导入长页独立滚动，标题、返回和确认可达；失败保留输入、目标和选择。

### 迷你播放器、完整播放与歌词

| 区域 | 布局 |
| --- | --- |
| 迷你播放器 | 有当前曲目或恢复队列时高 72px；封面、歌名、播放／暂停、下一首与只读细进度。空队列时收成 48px 聆听提示，不展示禁用控制 |
| 完整播放 | 隐藏主导航；封面、歌曲资料、进度、主控制、辅助操作依次排列 |
| 主控制 | 模式、上一首、播放／暂停、下一首、收藏 |
| 辅助操作 | 歌词、定时、队列直接可达；音量、倍速、快进退和具名样式选择进入更多 |
| 完整歌词 | 大字阅读区替代封面，歌曲资料收于顶部，保留控制区；与六种封面样式分开切换 |
| 短横屏 | 展示／歌词与歌曲资料及控制并排；空间不足允许滚动，不覆盖标题、版本及播放按钮 |

歌曲名和歌手常规最多两行、短屏一行；点击标题查看完整内容。来源／版本独立成行，入口至少 48px 高，数量和箭头保持完整。迷你条及唱片页不显示歌词预览，手机与桌面样式偏好独立保存。

歌词空状态提供查找／导入，失败增加重试；加载、纯音乐和未播放分别提示。未读到修订前禁止保存，关闭管理后返回歌词视图。

队列常规最高 88dvh；540–760px 且高度不超过 500px 时采用全高面板，标题与批量操作同行，列表独立滚动，评论切换、清空和关闭可达。正文与弹层按实际播放器、导航和安全区高度避让。

### 音乐库与长流程

收藏和自建歌单纵向排列为宽幅入口，名称与真实数量位于左侧，封面位于右侧。收藏用最多四张不同的真实歌曲封面拼贴，无图时保留心形；自建歌单优先使用手动封面，再取有封面的歌曲，缺图使用占位。新建为轻量入口，导入／导出与资料库维护进入管理面板。详情页头显示当前歌单名，正文使用 80px 封面、名称、数量和播放操作，添加、排序、搜索直接可见；标题旁可切换歌单，管理打开底部面板。

歌单、作者、合集详情隐藏主导航，保留迷你播放器。短操作用底部面板；版本、歌词、导入与维护使用全高页面。歌曲更多面板先显示摘要及常用动作，不撑高歌曲行。进入完整播放或添加版本搜索时保留原编辑器与草稿。

## 视觉方向

默认暖纸炭黑，明暗跟随系统。四套配色共用背景、正文、边框与面板，只在主要操作、进度、收藏、焦点和选中态体现主题色。

| 配色 | 白天主要操作 | 白天强调文字 | 黑夜主题色 |
| --- | --- | --- | --- |
| 暖纸炭黑 | `#252720` | `#AC3E27` | 主要操作 `#F2ECE1`，强调 `#EEA086` |
| 经典薄荷 | `#31C27C` | `#126D46` | `#43D99A` |
| 晴樱粉 | `#FF6699` | `#B62758` | `#FF80AB` |
| 珊瑚红 | `#FA233B` | `#BE263C` | `#FF6377` |

白天背景／面板为 `#F3F0E9`／`#FFFCF7`，黑夜为 `#1B1916`／`#27231F`。正文使用 `--text`，说明使用 `--muted`，主要按钮使用 `--primary/--on-primary`，选中、边框、危险和焦点使用对应语义变量；不在单页重建主题。

后三套主要按钮用深色文字，强调文字与按钮底色分别取值，文字对比度至少 4.5:1。内部 ID 为 paper、mint、ocean、plum；完整色值以源码为准。平台特色限于小图标、标签和前三名序号。

页面用留白与细分隔线分组，不给整列、表单和字段重复套卡片。当前项使用底色和文字，不加左侧装饰线；沉浸封面环境色受主题遮罩约束。

| 入队、加入歌单、预览 | `.btn-secondary` |

## 表单与弹窗

统一使用 `.field`、`.input`、`.select`、`.textarea` 和 `.choice`，标签常驻。桌面简单弹窗最大 480px，歌曲编辑最大 880px，复杂内容保留固定头尾及独立滚动。

`Modal` 管理 Esc、焦点限制、背景滚动锁定和焦点返回。首个输入用 `data-autofocus="true"` 在 dialog 打开后聚焦。冲突保留草稿并展示当前值，危险操作先显示影响再确认。

## 页面与内容

### 全局布局与播放条

普通页面最大 1600px，居中；展开队列先扣其宽度，再计算内容布局。队列默认关闭，页面切换保留手动状态；1050px 断点切换侧栏／抽屉，刷新后关闭。侧栏及队列背景延伸到底，内部内容独立滚动。

| 桌面播放条 | 规格 |
| --- | --- |
| 悬浮播放岛，默认 | 最大宽 1280px，高 88px，距底 16px，左右至少 16px，18px 圆角 |
| 底部长条 | 外壳铺满贴底，高 104px；内部限宽居中 |
| 共用 | 104px 正文占位；左右信息等宽、主播放键居中；切换不重建音频 |
| 窄桌面 | 761–1050px 紧凑间距；1250px 以下倍速和定时收进更多 |

睡眠面板区分生效规则与草稿，未提交显示「修改尚未生效」；快捷设置明确立即生效。剩余秒数统一向上取整，错误不显示完成提示。

### 导航与全局工具

桌面侧栏的歌单区独立滚动，粘贴链接、明暗与设置固定底部。正在播放页使用自己的返回与工具入口；Electron 顶栏为 40px 原生窗口控制区。设置当前项有语义选中态。

Windows 悬浮歌词有实际歌词才显示，隐藏后不留鼠标拦截区；前奏／间奏不因当前句空白反复隐藏。锁定时穿透，悬停约 600ms 显示 36px 解锁按钮，设置和托盘保留键盘解锁；展开快捷设置保持歌词位置。

悬浮歌词可调字号、颜色、单双行和翻译。托盘提供打开慢听、歌词开关、解锁、重置位置及退出。本地备份入口称「歌单 JSON 导入与导出」。

### 发现与内容封面

桌面栏目容器达到 600px 为三列，800px 为四列，最多四列。手机作者合集入口为两列；推荐使用重点封面与横向紧凑封面行，关注更新封面浏览使用两列 4:3 大图。普通列表、歌曲、榜单和合集入口使用方形封面；缺图用同尺寸占位，原图展示保留自然比例。

桌面推荐的刷新、保留内容及账号失效状态归属对应栏目，不在页面标题下插入整宽告警。已有歌曲时使用标题旁低强调的「正在更新／暂未更新」入口，原因、取消及重试进入原生 popover，支持 Esc 和焦点返回；没有可用内容才使用栏目内的失败空状态。刷新失败不移除歌曲或改变列表位置，不自动弹出提示。

### 列表、分页与歌单

- 列表平铺，统一序号、封面、对齐和当前项底色；桌面歌单普通歌曲行至少 64px。榜单和队列不增加表头。
- 分页复用 `Pagination`／`PagedList`，仅底部一栏，排列数量、首／前、页码、后／尾。桌面 36px、窄容器 44px，移动 48px；容器不超过 420px 分两行，未知总量禁用尾页。
- 桌面歌单以名称为主标题，128px 封面、数量与播放集中；管理菜单承载歌单操作及歌曲管理。自建歌单改名在前、删除在后，系统收藏不可改名或删除。
- 手动封面为可聚焦按钮，悬停／焦点显示相机及更换说明；弹窗支持上传、选曲、恢复自动、裁剪、拖动、方向键和缩放，关闭返回封面焦点。
- 歌曲行的多版本数量与固定标记可辨。桌面更多用浮动菜单，手机用底部面板；均不撑高原行。
- 桌面歌曲、封面、榜单、队列和歌单的右键与更多／管理共用 `ActionMenu`。右键仅打开并描边标识目标；菜单按播放、收藏整理、版本来源、列表操作分组，危险动作标明范围。使用主题面板、264px 宽和 12px 圆角，靠近鼠标或按钮定位并避让窗口边缘，内部可滚动。
- 菜单采用 menu／menuitem 语义；Shift+F10／菜单键打开，方向键及 Home／End 移动，Enter／空格执行，Esc 仅关闭菜单并还原焦点。点击外部、滚动所属列表、窗口失焦或改变尺寸关闭。输入框保留编辑右键，移动端保留原更多面板。
- 歌曲窗口区分播放版本与歌曲资料，默认、固定、试听分别操作；统一保存，搜索添加版本返回原草稿。
- 歌曲管理范围为当前收藏或任一歌单中的歌曲，归组／合并／移动目标使用同一范围。失去归属的目标清除选择和预览。整理建议按需打开，字段和依据明确，人工保护项不可覆盖。

### 正在播放与沉浸封面

| 区域 | 规格 |
| --- | --- |
| 普通播放 | 两栏最大 1120px，详情上限 520px；宽容器间距 96px，其余双栏 48px，容器不超过 750px 单列 |
| 展示槽 | 桌面上限 460px，单列 360px，并按高度收缩；原图保持比例 |
| 唱片／圆形 | 桌面为槽宽 80%，上限 360px；方形 76%，上限 340px |
| 旋转 | 顺时针 24 秒一圈，暂停／缓冲／隐藏保留角度；减少动态设置只关闭展示过渡 |
| 横向音波 | 固定中线真实频谱，48 根，宽度不足 340px 时 32 根 |
| 圆形音环 | 96／64 根镜像细线，静止红标签居中，中心不叠加歌曲封面 |
| 底部歌词 | PC 网页浏览页 36px 单行，可展开为 68px；播放页显示当前与下一句，手机和 Electron 不显示 |
| 沉浸歌词 | 大于 760px 启用，双栏最大 1280px，间距 48–112px；窄桌面 32px |
| 沉浸控制卡 | 最大宽 880px，高 88px，20px 圆角，距底 16px，正文预留 120px |
| 沉浸歌词文字 | 默认 28px／600、1.4 行高、句间距 24px，翻译 18px；可调 20–40px，当前句约位于 45% 高度 |

默认唱片；桌面按唱片、原图、方形、圆形、音波、音环循环，手机具名选择。唱片与音环使用红标签及字标，不叠加歌曲封面；音波使用真实频谱，暂停／静音回落，隐藏停止绘制，减少动态设置不关闭频谱。素材见[素材与来源](../参考/素材与来源.md)。

主控制为模式、上一首、播放／暂停、下一首、收藏，歌名旁提供词与更多。歌名最多两行，短屏单行，点击可展开；来源详情含原标题、上传者、分 P 及版本入口。

版本与歌词为非模态侧面板，支持键盘切标签；1100px 及以下打开时暂时收起普通封面，关闭恢复。试听不改收藏／默认，未保存校时关闭后撤销。

沉浸覆盖内容设为 `inert`，隐藏顶栏；Esc 先关上层再收起，退出回原焦点。队列与评论覆盖打开。普通 LRC 整句高亮，逐字只用真实时间；手动阅读 5 秒恢复跟随。减少动态效果时关闭歌词缩放、模糊和平滑滚动，渲染失败保留可定位正文和播放器。样式见 [desktop-lyrics.css](../../src/desktop-lyrics.css)。

### 设置与反馈

设置按分组进入，主题可即时选择。Windows 诊断称「运行信息」，复制按钮显示结果，只包含白名单字段；网页保留「诊断与数据」。

偏好保存失败在顶栏下持续提示及重试。状态读取失败提供资料目录入口；播放器已释放后的退出失败显示恢复页，提供「重试保存并退出」。

歌曲管理、封面与版本／歌词按需加载，失败可关闭或重试；区域渲染错误保留导航和音频，未保存输入可能丢失。空、加载及失败状态说明实际原因，不填充虚构内容。

## 复核方式

覆盖真实长标题、分 P、混合来源、未知封面、空列表、四套深浅主题、焦点与触控；桌面和移动分别回归。尺寸及用例见[验证规范](验证规范.md)。
