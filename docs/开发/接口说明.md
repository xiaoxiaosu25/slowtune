# 接口说明

当前 HTTP 契约，入口为 [server/index.ts](../../server/index.ts)。自动清单用于定位路由，主题表维护请求、响应及限制；当前不提供完整 OpenAPI schema。

按主题阅读：[通用约定](#通用约定) · [会话与访问](#入口会话与访问策略) · [设置](#欢迎页来源与搜索偏好) · [搜索与榜单](#搜索榜单与发现) · [账号](#b站账号与收藏夹同步) · [关注与评论](#作者关注与评论) · [歌曲资料](#歌曲资料路由) · [来源与媒体](#来源协议媒体与租约) · [歌词](#歌词) · [错误](#错误与状态)。

`X-SlowTune-Surface: desktop` 标记 PC 网页／Electron 的宽屏路径，不授予宿主控制权限。

## 通用约定

- 网页与接口同源。Host 必须位于 `allowedHosts`，带 Origin 的请求必须与请求 URL 同源。写请求除 `/internal/*` 外要求 `X-Music-App: 1`；JSON 正文使用 `Content-Type: application/json`。
- `/api/bootstrap`、`/api/welcome/image/:id`、`/api/login` 和 `/api/session` 不要求已有访问会话。其余 `/api/*` 与全部 `/v1/*` 要求有效的 HttpOnly、SameSite=Strict `music_session` Cookie。关闭进入验证仍需建立独立浏览器会话。
- 服务会话与 B站账号分别管理；访问会话失效返回 401 并包含 `X-SlowTune-Session: expired`。服务重启丢失访问会话；Cookie 是否 Secure 取决于请求协议。
- `/internal/*` 使用运行实例的 `X-Control-Key`，不以访问码或 B站 Cookie 替代。不要将控制密钥写入文档、示例 URL 或日志。
- 产品 JSON 失败一般为 `{error:{code,provider?,currentRevision?,upstreamCode?}}`；来源协议另带 `protocol`。图片、导出、媒体、SSE 和 204 响应按各自内容类型处理。
- `revision` 为读取得到的不透明修订，空资料库可能为 `null`；不能自行构造或跨用户空间复用。冲突后重读并保留用户草稿。
- 请求取消与会话撤销取消其在途任务；已提交事务不回滚。任务 ID、游标、快照与令牌具有归属及有效期，不能跨账号、来源状态或会话复用。
- 未另行注明时，产品 JSON 读取上限 2 MiB。表内 `{}` 表示发送空 JSON 对象。未知 `/api/*` 返回 JSON not-found／404；客户端仍须检查 Content-Type。

## 共享数据结构

| 结构 | 字段与含义 |
| --- | --- |
| `EntryRef` | `{provider:'bilibili'/'youtube',kind:'video'/'playlist',id,part?}`；B站具体 P 使用元信息取得的真实 cid |
| `MusicEntry` | `{ref,resourceId,title,url,artwork?,durationSeconds?,uploader?:{id?,name},artists?,tags?,categories?,board?,publishedAt?,parts?}`；缺失字段保持未知 |
| `Page` | `{items,nextCursor?}`；使用来源返回的下一页游标，不自行递增 |
| `SongLibraryState` | `{modelVersion:1,revision,snapshot}`；snapshot 保存歌曲、版本、收藏、独立歌单成员与目录关联 |
| `WelcomeState` | `{revision,welcome:{background,imageId?,desktopFocus:{x,y},mobileFocus:{x,y},shade,position}}`；焦点为 0–100，遮罩为 0–70 |
| `SourceSettingsState` | `{revision,sequence?,youtube:{enabled,disabledDisplay,available,checking,toolVersion?,issue?}}`；显示策略为 show、dim、hide |
| `CreatorRef` | `{provider,id}`；`CreatorProfile` 增加 `{name,url,artwork?}`；关注项再增加 `followedAt` |
| `FollowState` | `{revision,creators}`，creators 为关注作者数组 |
| `SongSyncState` | `{accountId,revision,links,busy,folders?}`；仅当前账号的关联，包含具体映射、未映射成员数、待核对状态与最近同步 |

## 入口、会话与访问策略

| 方法 | 路径 | 请求 | 响应与副作用 |
| --- | --- | --- | --- |
| GET | `/api/bootstrap` | 无；公开 | WelcomeState 加 `{authenticationRequired,authenticated}`，不返回访问码摘要 |
| GET | `/api/welcome/image/:id` | 路径为图片 ID；公开 | raster 图片正文与 MIME；不存在返回空 404；登录前可读取 |
| POST | `/api/session` | `{}`；仅关闭进入验证时可用 | `{ok:true}` 与访问 Cookie；有效会话可复用；开启验证时 401 |
| POST | `/api/login` | `{accessKey}`，正文上限 4096 字节 | `{ok:true}` 与访问 Cookie；替换当前浏览器旧会话；错误访问码 401、限流 429 |
| POST | `/api/logout` | 无必需字段 | `{ok:true}`；移除当前访问 Cookie、取消所属任务，不退出共享 B站账号 |
| GET | `/api/settings/access` | 无 | `{revision,authenticationRequired}` |
| POST | `/api/settings/access` | `{revision,currentAccessKey,authenticationRequired,newAccessKey?}`，上限 4096 字节 | 新访问策略；保留当前会话、撤销其他旧会话并取消其任务 |

新访问码为 6–256 字符且不能全为空白。仅切换进入验证时可省略新访问码，仍须验证当前访问码。失败尝试限流；关闭验证不关闭 API 会话检查，不能据此将接口视为无需身份。

```json
{"revision":"从读取取得","currentAccessKey":"示例访问码","authenticationRequired":true,"newAccessKey":"新的示例访问码"}
```

榜单组合为 netease 的 hot/new/rising、qq 的 hot、bilibili 的 hot 与可用期次、apple 的 most-played。榜单读取可返回保留内容与 issue，不能把上游失败写成空榜。`/api/comments` 与 `/api/charts` 的不支持方法返回 405。YouTube 地区默认 HK，可用地区由[地区类型](../../server/youtube-regions.ts)定义；shared 读取会记录当前地区偏好。

桌面自动选源显式提交 `searchMode:'title-artists'`；移动端省略该字段。该字段控制本次查询顺序和自动候选的音频可读性检查，不保存到歌曲、指定版本或队列。两种模式缓存隔离，均以原歌名和歌手执行匹配规则；搜索／分类失败、取消或修订变化停止后续查询。桌面候选音频明确受限、不存在、过期或不支持时继续后续合格候选；网络、登录、限流、超时及服务错误仍停止。公开 B站搜索、分区读取及指定来源元信息不附带登录凭据。

桌面同时提交实际播放器支持的 `audioSupport` MIME/codec 字符串数组（最多 32 项，每项最多 128 字符，如 `audio/mp4; codecs="fLaC"`），仅用于本次自动候选选轨并参与缓存隔离。检查按播放器的音质顺序尝试可解码音轨；单音轨明确失效时先尝试同视频的下一音轨，全部不可用才换候选。成功返回的 `entry.verifiedAudio` 含实际 ref、format，桌面准备上下文中还可附带 preparationToken；实际播放及当前资源地址刷新沿用此音轨，不重新选回被拒音轨，新一轮选播重新检查。令牌只用于首播移交，能力和检查结果均不写入歌曲或持久队列。移动端不提交能力，保留原路径。

```json
{"provider":"bilibili","query":"歌曲名","song":{"title":"歌曲名","artists":["歌手"]}}
```

自动匹配有界、可取消；指定失效返回 preferred-unavailable，不静默换曲。读取权限、网络、限流或来源故障不会被当作无匹配。具体偏好和匹配规则见[产品功能](../产品/产品功能.md#音乐榜单)。

维护 action 的精确字段见 [song-library-maintenance.ts](../../server/song-library-maintenance.ts)。每个关联最多确认 10000 个成员，合并后的远端集合最多 10000 个 BV；远端成员按完整有界分页读取。每轮最多准备并导入 100 个新增视频，其余在后续轮次继续，游标轮转避免失败项阻塞后续成员。无法完整读取远端列表时不据此推断删除。后台约每 2 分钟运行，发送每个请求前重读当前关系与意图，暂停、解除、账号切换和更新的编辑均可使旧工作失效。每个会话只保留一个同步预览，服务最多保留四个，五分钟到期。

整理建议的 candidate 为 `{id,patch,evidence}`，patch 只含可采用的歌名／歌手，evidence 区分目录资料、来源歌手资料与标题提取。每次最多检查所属歌曲的 20 个版本与 10 条目录资料，保留 6 个候选，每项最多 3 条依据；候选歌名最多 200 字符，歌手最多 8 位、每位 200 字符，超长资料跳过而不截断。人工保护字段不提供覆盖候选，标题提取不替换已确认目录字段；合集、串烧与歧义只提供提示和独立候选，不触发归组。预览每会话一份、全服务最多 32 份，5 分钟到期；采用须重验会话、预览、修订与字段保护，不接受客户端传入候选值，成功后令牌失效。建议只在内存中保存，不进入完整聚合或备份。

快照固定 `format:'slowtune-library',version:1`，包含 songs、versions、favorites、playlists、catalogLinks、redirects；所有嵌套对象严格解码。快照正文最大 64 MiB（67,108,864 字节），按 UTF-8 原始字节流限制，不先无界解析。导入预览五分钟到期，每会话保留一份、全服务最多四份；超额为 invalid-input。退出、身份替换、撤销、会话到期或服务停止均清理所属预览；其他会话不能提交该预览。

Song 可附加 `desktopCatalog:{state,checkedAt,selection?,record?,issue?}`；state 为 matched/review/not-found/error/disabled，仅 matched 含 automatic/manual 的 selection 及目录 record。`SongCatalogRecord` 为 `{provider:'netease',id,title,artists,album?,artwork?,durationSeconds?,url}`。`fields.artwork` 可选，结构与其他字段保护一致。缺失这些可选字段的版本 1 快照仍有效；原始 Song 的歌名／歌手／封面保持手机路径，桌面通过独立投影显示所选目录且保留人工字段。后台每次处理一首，成功后约 5 秒继续，空闲／网络失败至少 60 秒后检查；错误歌曲一小时、无结果歌曲七天后才自动重试，review/matched/disabled 需人工更换。不传入客户端候选资料，不更改播放版本或归组关系。

追加身份／资料冲突阻止提交；替换完整恢复成员顺序并展示移除范围。恢复成员形成独立本地贡献，受影响同步关联转待确认，不自动恢复远端删除权限。冲突为 409、会话／Origin 为 401／403、过期为 410、取消为 408、存储为 503，其余输入／关系错误为 400。

编辑命令见[编辑边界](../../server/song-library-edits.ts)，受信事务见[歌曲资料模块](架构与数据.md#歌曲资料模块接口)。仅接受当前数据格式。

sources 检查来源启用状态、账号／来源代次与取消，新来源在异步取源后再次检查；事务内重新核对修订和确切来源归属。同名不自动合并，来源已属于其他歌曲时拒绝。playlist 的 duplicates 为 allow/skip/reject，默认允许独立重复成员。追加版本保留现有默认，仅首个版本自动成为默认。批量页面暂存最多 1000 项／100 页的来源预览，单次提交最多 500 项；提交复用资料库已有确切版本，其余由服务取得元信息，不信任页面预览中的资料事实。来源事实与可用性需要刷新时使用维护检查。

| --- | --- | --- |
| metadata | `{ref:EntryRef}` | MusicEntry |

```json
{"protocol":2,"provider":"bilibili","request":{"query":"歌曲名","mode":"video","limit":20}}
```

该示例用于 `/v1/call/search`。平台 Cookie、账号上下文和来源头由宿主管理，客户端不能指定任意凭据或媒体地址；临时 URL、租约和工具句柄不进入资料快照。

桌面在 JSON／来源请求中提交 `X-SlowTune-Surface: desktop`；会话保护后，仅来源调用、搜索、点播、识别及发现／目录读取进入最长 60 秒的有界准备上下文，资料写入、批量保存、导入、媒体与租约请求不使用此操作预算。桌面歌曲点播的来源超时返回 timeout／503，取消仍为 cancelled／408。响应可包含 `X-SlowTune-Operation` 供本地诊断关联。桌面握手的 operations 可含宿主扩展 `slowtune-desktop-audio`，它不新增 operation 路径：客户端向原 `/v1/call/prepare` 提交原协议正文，并在 `X-SlowTune-Audio-Support` 头提交上述 MIME/codec 数组的 JSON，由服务完成最佳音轨枚举和准备。可选 `X-SlowTune-Preparation` 是 32 字符的不透明 preparationToken，最长 15 秒、单次消费，绑定当前访问会话、来源代次、确切 ref 和可解码音轨；不符或过期重新准备，不返回或接受原始交付 URL。无桌面头的握手、准备和移动端请求保持原契约。

桌面相同搜索、完整匹配和必要的原始取源请求仅合并在途工作，身份包含会话、账号／来源代次、全部结果参数、相关设置修订与解码能力；最多 64 份，共享结果在正式租约发布前结束。每个等待者独立取消，最后一个等待者退出才取消底层工作；失败不缓存。点播加入等待中的预取时提升共享任务的调度优先级。

`/api/status` 与 `/internal/diagnose` 额外返回 desktopPlayback，含 active、pending、inflight、tickets、最近 160 条安全 events，以及这些窗口样本按 operation 汇总的 timings（samples、p50、p95，毫秒）。事件只含操作类别、阶段、时间、状态码和错误类别，不含令牌、Cookie、签名地址或曲目身份；进程重启不保留。

## 歌词

歌词接口已挂载 `/api/lyrics`，复用宿主的 Host、同源、访问会话、请求取消与 `X-Music-App: 1` 保护。所有接口使用 POST，正文最多 790,528 字节；只接受列出的字段。用户空间由配置确定，不能在 JSON 中指定。`ref` 必须是确切 BV＋cid 或 YouTube 视频 ID，不接受 URL、临时媒体信息和无 cid 的 BV。

`X-SlowTune-Surface: desktop` 的自动匹配与歌手歧义检查共用[桌面歌手别名](../../server/desktop-lyric-match.ts)，只归一明确登记的同一歌手名称，当前包含周杰伦的简繁体及 Jay Chou；歌名、版本、时长和完整搜索要求不变。无此头的既有路径不应用别名规则。桌面客户端另支持从「《歌名》歌手｜说明」提取后置歌手，不从宣传文案、合集或翻唱原唱署名猜测演唱者。

| 方法 | 路径 | 请求 | 响应与副作用 |
| --- | --- | --- | --- |
| POST | `/api/lyrics/state` | `{ref}` | 当前来源的 `{revision,offsetMs,document}`；无选择时修订为 null；只读本地，不请求上游 |
| POST | `/api/lyrics/resolve` | `{ref,title,artist?,durationSeconds?}` | `{state,matched,candidates,issues}`；已有正文直接恢复，否则自动查询并条件保存可靠结果；歌名与版本精确一致，已知歌手须一致且时长差不超过 12 秒，未知歌手须时长差不超过 5 秒且无不同歌手歧义；最多尝试 3 份正文；查询期间发生并发保存则返回最新选择，不覆盖 |
| POST | `/api/lyrics/search` | `{title,artist?,durationSeconds?}` | `{candidates,issues}`；网易云／LRCLIB 各最多 12 个候选，按歌名、歌手、时长排序；提供方部分失败仍保留成功候选；不采用歌词 |
| POST | `/api/lyrics/search-progress` | 同 search，仅 `X-SlowTune-Surface: desktop` | `application/x-ndjson`，逐行完整 `{candidates,issues,complete}` 快照；最终 complete=true，失败为 `{error:{code}}`；取消断开当前等待，预览和保存沿原接口 |
| POST | `/api/lyrics/document` | `{provider,id}` | 从固定提供方地址读取并解析 LyricDocument；provider 仅 netease／lrclib，id 为正整数串；预览和缓存不改变选择 |
| POST | `/api/lyrics/select` | `{ref,revision,candidate:{provider,id}或null}` | 条件保存所选正文快照并将偏移归零；null 清除选择但保留新的修订；返回 LyricState |
| POST | `/api/lyrics/import` | `{ref,revision,title,text}` | 导入 LRC／纯文本并条件保存；UTF-8 正文最多 128 KiB、4000 行、单行最多 2000 字符；返回 LyricState |
| POST | `/api/lyrics/offset` | `{ref,revision,offsetMs}` | 仅限逐行歌词，整数毫秒范围 ±600000，正数延后显示；条件保存并返回 LyricState |

候选含提供方、ID、歌名、歌手、可用专辑／时长及同步类型。正文行含 `startMs`（纯文本为 null）、`text`、可选 `translation` 和逐字数据 words；当前提供方不生成逐字时间。来源元信息由服务读取，不接受任意 URL。not-found 为 404，conflict 为 409 并返回修订，cancelled 为 408，busy／rate-limited 为 429，网络／超时／上游／存储失败为 503。迟到预览不覆盖当前界面。

## 错误与状态

| 范围 | HTTP 与 code |
| --- | --- |
| 公共保护 | host-denied/origin-denied 为 403，stopping 为 503，会话 authentication 为 401；访问会话容量或限流可为 429 |
| 产品业务 | conflict 409；authentication 401；expired 410；busy/rate-limited 429；restricted 403；cancelled 408；invalid-input/unknown-version/duplicate/not-found 400；其余通常 503 |
| 搜索和启动设置 | MusicSearchError、StartupError 在当前产品映射为 400；登录失败访问码单独映射为 401，设置中当前访问码失败为 400 |
| 来源服务 | not-found/expired 404；invalid-input/stale-cursor 400；authentication 401；restricted 403；busy/rate-limited 429；cancelled 408；其余 502 |

业务必须同时检查 HTTP 状态、error.code 和可选 provider/upstreamCode；B站账号失效与访问会话失效分别处理。不确定的网络或权限错误不等同于内容不存在。展示文案由[客户端错误映射](../../src/api.ts)维护。
