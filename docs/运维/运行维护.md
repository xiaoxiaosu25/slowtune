# 运行维护

本页说明独立克隆和现行产品的通用运行方式。当前主要维护 Windows 桌面，支持与验收范围见[当前限制](../产品/当前限制.md)。

## Windows 桌面运行

按 [README](../../README.md#源码启动) 安装依赖并构建。`npm run desktop` 或仓库根的 `一键启动.cmd` 打开已有构建；重复打开唤起原窗口。修改源码后执行 `npm run desktop:restart` 有序退出、重建并打开。独立克隆默认构建到 `local/desktop-build/`；开发路径由 [workspace-paths.mjs](../../scripts/workspace-paths.mjs) 解析。

源码桌面资料保存在项目根 `data/`，免安装版保存在 EXE 同级 `data/`。桌面自动创建内部配置、选择回环端口和建立会话，无需选择服务配置或输入访问码。关闭主窗口会结束播放并停止本桌面的服务，最小化可继续播放。

只有在需要生成发行程序时才执行 `npm run desktop:package`。完整解压后的程序可独立运行；当前没有签名、安装器或自动更新。YouTube 工具需要另行配置。

发行时从已确认的源码提交构建，检查完整 ZIP 解压后的程序，再以相同版本标签创建 GitHub Release 并上传该 ZIP。开发预览版标记为 Pre-release，发行说明注明 Windows 架构、使用方式、验证范围和已知限制。程序包不提交源码 Git；GitHub 自动生成的源码压缩包不能代替程序 ZIP。

## 实例目录

| 桌面 data 下的位置 | 内容 |
| --- | --- |
| `instance/config.local.json` | 自动生成的内部配置 |
| `library/` | 歌曲、歌词、关注、推荐和设置等 SQLite 资料 |
| `preferences.json` | 队列、主题等端口无关偏好 |
| `desktop-state.json` | 主窗口与悬浮歌词状态 |
| `profile/` | Electron 浏览器资料 |
| `runtime/` | 运行记录与当前用户加密的账号凭据 |
| `logs/`、`cache/` | 日志与可再生成缓存 |

桌面不继承服务版配置，也不接管其进程。服务版资料由配置中的 `database` 和 `runtimeDirectory` 决定；相对路径以配置文件所在目录为基准。数据目录、构建输出与测试输出分别管理，构建不会清理日常 data。

## 资料备份

歌单 JSON 使用 `slowtune-library` 版本 1，包含歌曲、版本、收藏、歌单成员和格式内的可移植资料，正文最多 64 MiB。导入先预览，替换需要确认；它不包含账号凭据、应用关注、推荐和来源设置、歌词库及完整桌面偏好。

完整备份先正常退出桌面并等待服务结束，再复制整个 data；恢复时保留原目录，将完整副本放到所需的可写位置。服务版完整备份按实际配置保存资料文件与必要运行资料，连同 SQLite 的 WAL／SHM 状态一起处理。更新免安装程序时保留自己的 data。

B站凭据绑定 Windows 用户，换机器或用户后可能需要重新登录。导入歌曲 JSON 不恢复远端删除权限；受影响的同步关联需要核对映射并确认恢复，具体契约见[接口说明](../开发/接口说明.md#新歌曲资料路由独立模块)。

## 服务配置与启停

服务版入口仍可使用。先执行 `npm ci` 和 `npm run build`，再复制 [config.example.json](../../config.example.json) 为项目根 `config.local.json`，将 `accessKey` 改为私有随机值。桌面用户无需进行这一步。

示例默认回环监听，数据库前缀为 `./data/library.sqlite`、运行目录为 `./runtime`。歌曲资料库使用该前缀追加 `.song-library.sqlite`，其他模块按各自后缀保存。`MUSIC_APP_CONFIG` 可指定另一份配置文件；显式指定的文件缺失时启动失败。

```powershell
npm start
npm run diagnose
npm run stop
```

`npm start` 运行已有服务构建；关闭浏览器不停止服务。启停与诊断共用配置定位规则。`npm run reset-access` 在目标服务停止后将访问策略恢复到配置中的访问码，随后应进入设置修改。`node scripts/launch.mjs --no-open` 提供构建和端口检查、实例复用与启动入口。

只有明确需要局域网服务时，才配置 `host: "0.0.0.0"`，将实际地址加入 `allowedHosts` 并自行处理防火墙。HTTP 不提供 HTTPS 的传输保护。现有手机网页属于服务版，移动端开发继续暂停。

`npm run update` 是已有服务实例的停止、备份、重建与重启入口，不拉取 Git 或安装依赖。日常源码更新先提交／同步源码，再安装变化的依赖，按所选运行形态重新构建。`desktop:adopt` 是已有服务资料接入桌面的可选维护入口，新用户不需要执行；它要求源实例退出并保留备份，非空目标拒绝覆盖。

## 来源工具与账号

B站支持匿名读取和扫码登录后的对应能力。收藏夹关联可能双向修改远端内容，使用前核对目标；本地 JSON 恢复与远端同步权限分别管理。

YouTube 默认关闭。需要时在私人配置中提供 `ytDlp`，例如：

```json
{
  "ytDlp": {
    "executable": "C:/path/to/yt-dlp.exe",
    "nodeRuntime": "C:/path/to/node.exe"
  }
}
```

以上为示例路径，应替换为实际工具。Python 模块方式还可提供 `prefixArgs: ["-m", "yt_dlp"]` 并将 executable 指向 Python。应用不自动安装工具；开关开启不代表工具已就绪，实际状态见设置中的检查结果。

## 故障诊断

| 现象 | 处理 |
| --- | --- |
| 构建缺失或版本不一致 | 完成依赖安装和构建，再重新打开对应应用／实例 |
| 本地设置未保存 | 检查磁盘与目录权限，使用应用内重试入口，保存后再退出 |
| 窗口状态文件读取失败 | 保留原文件，排查占用／权限；损坏时从有效备份恢复或另行保留原文件后重建 |
| 端口占用或归属不符 | 用诊断确认实例；不结束未知进程，服务配置可选择其他端口 |
| Host／Origin 被拒绝 | 核对白名单、实际地址与同源请求，白名单使用主机名或 IP |
| B站登录无法恢复 | 核对 Windows 用户，必要时重新扫码 |
| YouTube 不可用 | 核对工具路径、参数、Node runtime 和检查状态 |
| 保存冲突或导入失败 | 保留草稿，重读当前修订并核对格式、限额及同步影响 |

桌面可在设置中打开资料／日志目录，并显式复制白名单诊断信息；该入口不自动上传。公开反馈前去除凭据、账号二维码、私人路径与媒体签名地址。测试方法见[验证规范](../开发/验证规范.md)。
