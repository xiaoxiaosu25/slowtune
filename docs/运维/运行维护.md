## Windows 桌面运行

按 [README](../../README.md#源码启动)安装和构建。`npm run desktop` 或 `一键启动.cmd` 打开已有构建，重复打开唤起原窗口；源码变更用 `npm run desktop:restart` 保存退出、重建并打开。

独立克隆构建默认在 `local/desktop-build/`，由 [workspace-paths.mjs](../../scripts/workspace-paths.mjs)解析。源码桌面资料在项目根 `data/`，免安装版在 EXE 同级 `data/`。宿主自动配置回环端口及会话，关窗停服，最小化继续播放。

明确要求发行时才运行 `npm run desktop:package`。从确认的提交构建，完整解压验证后发布同版本标签及 ZIP，标题为 `慢听 SlowTune v<版本>`，不用预发布标记，设为 Latest，并更新 README 下载链接。发行说明写明架构、使用方式、验证范围和限制；源码 ZIP 不能代替程序 ZIP。当前无签名、安装器或自动更新。

## 实例目录

| 桌面 data 内位置 | 内容 |
| --- | --- |
| `instance/config.local.json` | 自动生成的内部配置 |
| `library/` | 歌曲、歌词、关注、推荐和设置 SQLite |
| `preferences.json` | 队列、主题等偏好 |
| `desktop-state.json` | 窗口与悬浮歌词状态 |
| `profile/` | Electron 浏览器资料 |
| `runtime/` | 运行记录及当前用户加密凭据 |
| `logs/`、`cache/` | 日志与缓存 |

桌面不继承或接管服务版。服务资料由配置 `database` 和 `runtimeDirectory` 决定，相对路径基于配置文件目录。构建不清理持久资料。

## 资料备份

| 方式 | 包含 | 不包含／限制 |
| --- | --- | --- |
| 歌单 JSON | 歌曲、版本、收藏、歌单、目录资料及手动封面 | 不含音频、歌词库、账号、关注、推荐／来源设置、远端同步权限及队列 |
| 欢迎页 JSON | 图片与构图 | 不含访问策略和账号 |
| 完整桌面 data | 本地库、歌词、设置、凭据、队列、主题与窗口偏好 | 换机器或 Windows 用户后可能需重新登录 B站 |

歌单格式为 `slowtune-library` 版本 1，最多 64 MiB；导入预览后追加或替换，替换须确认范围。导入不恢复远端删除权限，相关关联须重新核对。

完整备份先正常退出并等待服务结束，再复制整个 data。服务版先停目标实例，按实际配置备份全部数据库及必要运行资料；存在 WAL／SHM 时一并保留。浏览器自己的队列和主题不在服务端备份中。

## 更新与恢复

1. 正常退出，备份完整 data。
2. 新 ZIP 完整解压到新的可写目录，将 data 副本放到 EXE 同级，保留旧程序及原始备份。
3. 打开并核对版本、资料、歌词和偏好；失败时保留现场再排查。

恢复前退出目标程序并另行保留原资料，再恢复完整目录。回退使用与旧程序匹配的备份，不让旧程序直接读取未经确认的新格式。

源码桌面先同步源码，依赖变化时执行 `npm ci`，再 `npm run desktop:restart`。服务版更新入口见下节。

## 服务配置与启停

执行 `npm ci`、`npm run build`，复制 [config.example.json](../../config.example.json) 为项目根 `config.local.json`，设置私有随机 `accessKey`。桌面用户无需此配置。

示例监听回环地址，数据库前缀 `./data/library.sqlite`，运行目录 `./runtime`；模块在数据库前缀追加各自后缀。`MUSIC_APP_CONFIG` 可指定另一文件，显式文件缺失则启动失败。

```powershell
npm start
npm run diagnose
npm run stop
```

`npm start` 只运行已有构建，关浏览器不停服。`node scripts/launch.mjs --no-open` 提供构建检查、实例复用及无浏览器启动。`npm run reset-access` 需停服后执行。

`npm run update` 停止目标实例、备份、重建并重启，不拉取 Git 或安装依赖。`npm run desktop:adopt` 用于接入已有当前格式资料，要求源实例停止、保留备份且目标为空，不转换历史模型。

## 手机与局域网访问

独立桌面内部服务只限本机，手机使用单独服务版，其资料不会自动接入桌面 data。

1. 按上节准备服务配置，保留访问验证并设置私有码。
2. 设置 `host: "0.0.0.0"`，在 `allowedHosts` 保留 localhost／127.0.0.1，并加入电脑实际局域网 IP。白名单只写主机名或 IP。
3. 在可信网络开放所选端口的防火墙访问，确保电脑与手机可互相到达。
4. 手机打开 `http://<电脑IP>:<端口>`，输入服务访问码。

例如 IP 为 `192.168.1.20`、端口 `4187` 时，访问 `http://192.168.1.20:4187`，白名单加入 `192.168.1.20`；示例值须替换。HTTP 不加密，电脑休眠、停服或换地址会影响连接。

同服务共享歌曲、歌单及账号；队列、主题和显示偏好由各浏览器保存。设备边界见[当前限制](../产品/当前限制.md)。

## 来源工具与账号

B站可匿名读取或扫码登录；收藏夹关联可能修改远端新增／删除，先核对预览。

YouTube 默认关闭，私人配置需显式提供工具，例如：

```json
{
  "ytDlp": {
    "executable": "C:/path/to/yt-dlp.exe",
    "nodeRuntime": "C:/path/to/node.exe"
  }
}
```

路径为示例。Python 模块方式将 executable 指向 Python，并设 `prefixArgs: ["-m", "yt_dlp"]`。应用不自动安装工具；启用后在来源设置检查实际状态。

## 故障诊断

| 现象 | 处理 |
| --- | --- |
| 构建缺失或版本不一致 | 安装依赖并构建，重开对应实例 |
| 设置保存失败 | 检查磁盘及权限，重试保存后退出 |
| 状态文件读取失败 | 保留原件，检查占用／权限，再恢复有效备份或明确改名后重建 |
| 端口占用或归属不符 | 用诊断确认实例，换服务端口，不结束未知进程 |
| 手机连接失败 | 检查实际 IP、端口、网络、防火墙及电脑是否休眠 |
| Host／Origin 拒绝 | 核对白名单和实际同源地址 |
| B站凭据无法恢复 | 核对 Windows 用户，必要时重新扫码 |
| YouTube 不可用 | 检查工具路径、参数、Node runtime 及来源检查结果 |
| 冲突或导入失败 | 保留草稿，重读修订并核对格式、限额及同步影响 |

桌面设置可打开资料／日志目录及复制白名单诊断；公开反馈前脱敏。检查方法见[验证规范](../开发/验证规范.md)。
