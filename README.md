# 慢听 SlowTune

慢听是一款 Windows 桌面个人音乐应用，支持 B站及按需启用的 YouTube 视频来源，提供搜索、在线播放、歌单、收藏、歌曲资料管理和歌词显示。

**当前为开发预览版。** 完整实机验收仍待完成，已知限制见下文。当前公开使用范围以 Windows 桌面版为主。

## 功能

- B站音乐发现、搜索、榜单与关注更新；可选扫码登录及收藏夹关联。
- 歌单、收藏、歌曲多版本管理和 JSON 资料备份。
- 播放队列、播放模式、音量、倍速及睡眠定时。
- 沉浸歌词与桌面悬浮歌词，支持歌词选择、导入和偏移调整。
- 本地资料独立保存，提供主题、外观设置和脱敏诊断复制。

完整行为见[产品功能](docs/产品/产品功能.md)。

## 源码启动

准备 Windows 和 Node.js `>=24.15.0`（需要内置 `node:sqlite` 及 npm），在仓库根目录操作。

`workspace.paths.json` 是作者 Studio 工作区的开发路径声明。普通独立克隆请先将它另存为被 Git 忽略的本地文件，使现有路径解析使用仓库内的 `local/`：

```powershell
Move-Item -LiteralPath workspace.paths.json -Destination workspace.paths.local.json
npm ci
npm run desktop:build
npm run desktop
```

在作者 Studio 工作区内维护时保留原路径声明，直接执行后三条命令。公共依赖已固定在仓库的 `vendor/`，安装慢听不需要另行取得整个 platform。公共包源码及其重建说明见 [vendor/README.md](vendor/README.md)。

构建后也可双击根目录的 `一键启动.cmd`。源码改动后执行 `npm run desktop:restart` 重建并打开；该命令不会自动安装依赖。

## 桌面包与资料

如果取得对应版本的 Windows 免安装包，完整解压到当前用户可写的目录，双击 `SlowTune.exe` 即可；免安装包附带 Node 运行时。源码仓库中的命令需要自行安装 Node 和开发依赖。

源码运行的资料在仓库根 `data/`；免安装包的资料在 EXE 同级 `data/`。关闭主窗口会保存并退出，最小化可继续播放。更新程序时保留 `data/`，完整备份须先退出应用再复制整个目录。

歌单 JSON 导出仅覆盖该格式包含的歌曲、版本、收藏和歌单等资料，不能代替完整应用备份。换电脑或 Windows 用户后，B站账号可能需要重新登录。详情见[运行维护](docs/运维/运行维护.md)。

## 音乐来源与限制

- B站和 YouTube 通过非官方接入方式提供内容；接口、账号权限、地区和网络变化可能使功能不可用。
- YouTube 默认关闭。启用需要可访问其服务的网络，并在桌面内部配置文件 `data/instance/config.local.json` 中显式配置 yt-dlp 与兼容的 JS 运行时／EJS；工具配置见[运行维护](docs/运维/运行维护.md#来源工具与账号)。这些外部工具未随应用分发。
- 开启B站收藏夹关联后，本地新增和删除可能同步修改远端收藏夹，请先核对操作范围。
- 真实来源长期播放、实体媒体键、实际休眠唤醒、多显示器浮窗、干净 Windows 交付和升级回退仍待完整验收，详见[桌面方案](docs/计划/桌面应用方案.md#剩余任务与完成条件)。
- 首发维护范围为 Windows 桌面。仓库保留其内部服务及既有网页实现；移动端开发冻结，其他系统支持尚未确认。
