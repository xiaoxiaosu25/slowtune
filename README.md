# 慢听 SlowTune

发现喜欢的音乐，留下想听的版本。

慢听是一款面向 Windows 的个人音乐播放器。搜索 B站音乐、整理自己的歌单，在唱片与歌词之间切换，让音乐陪你工作、散步或度过一个安静的夜晚。

## 下载 Windows 版

1. 打开 [Releases](https://github.com/xiaoxiaosu25/slowtune/releases)，选择标记为 **Pre-release** 的版本。
2. 下载附件中名称为 `SlowTune-<版本>-windows-x64.zip` 的程序包，完整解压到当前用户可写的目录。
3. 双击 `SlowTune.exe`，欢迎页结束后即可进入。无需另装 Node.js。

请保留完整解压目录；GitHub 自动生成的 `Source code.zip` 是源码，不能直接作为程序运行。更新前退出慢听，备份并保留 `SlowTune.exe` 同级的 `data/` 文件夹。

当前程序未签名，没有安装器或自动更新；支持范围与设备验证情况见[当前限制](docs/产品/当前限制.md)。

### 从发现到播放

在发现页浏览 B站音乐推荐，也可以输入歌名、歌手或粘贴支持的来源链接。应用内关注让你集中查看喜欢的作者、合集和最近更新，不会修改平台上的关注关系。

![慢听真实榜单页面：网易云热歌榜、歌曲封面与歌手、来源更新时间、收藏和搜索入口](docs/images/charts.jpg)

榜单集中展示网易云热歌／新歌／飙升榜、QQ 热歌榜、B站热歌榜和 Apple Music 中国区热门歌曲。可以单首点播、播放整榜，或点击搜索入口挑选其他版本；页面保留来源、更新时间与原榜链接。

榜单用于发现歌曲，实际播放会在支持的 B站、可选 YouTube 来源中匹配版本。来源不可用或版本不合适时，可以手动选择，不代表直接播放各榜单平台的音源。

### 给每首歌一个播放舞台

点击播放条进入完整播放页，选择黑红唱片、原始封面、方形封面、慢转圆形、横向音波或圆形音环。音波使用当前音频的实时频谱，播放页显示来源与实际可用的格式、码率等信息。

播放队列支持重排、上一首／下一首、顺序、随机、列表循环与单曲循环。进度、音量、倍速、快进退集中在播放器中；浏览其他页面时，底部播放条继续控制当前音乐。

### 睡前让音乐自行结束

| 结束条件 | 适合什么时候 |
| --- | --- |
| 倒计时 | 再听一段时间，到点结束 |
| 自然播完 N 首 | 包含当前曲剩余部分，听完几首再休息 |
| 播完当前曲 | 保留这一首的完整结尾 |

桌面定时结束动作可选择暂停或停止；独立 Windows 程序还支持退出慢听。自定义规则点击“开启定时”或“应用设置”后生效，手动切歌或直接拖到末尾不会计作自然播完一首。

### 跟着歌词，听完整首歌

播放后自动尝试匹配歌词，点击“词”进入完整歌词视图。桌面沉浸模式左侧保留唱片或封面，右侧跟随进度显示歌词，底部集中控制播放；Windows 独立桌面还可打开悬浮歌词，在使用其他窗口时继续看词。

歌词不合适时，可以人工搜索并预览候选，或导入 LRC／文本。歌词略快或略慢时，通过时间校准提前、延后，再保存到当前播放版本。有真实逐字时间的数据按逐字呈现，普通 LRC 按整句高亮；不同编曲应选择对应歌词。

### 一首歌，保留多个版本

把喜欢的音乐加入收藏与歌单，为同一首歌保留录音室、现场、翻唱等不同版本。歌曲资料与播放版本分别管理，整理歌名、歌手时仍保留确切来源。

- **歌曲默认版本**：平时点播这首歌时使用自己喜欢的版本。
- **歌单固定版本**：例如日常歌单听录音室版，现场歌单保留现场版，分别选择。
- **歌单整理**：支持封面更换、歌名／歌手搜索、排序、重排和 JSON 导入导出；导入前先预览内容。

### 在手机上继续浏览

移动网页使用“发现、音乐库、我的”导航，搜索有独立页面。迷你播放器可以直接播放／暂停和进入完整播放页，完整播放页可直接切换歌词；返回后继续浏览原来的歌单或搜索结果。

手机需要连接已配置的服务版。同一服务共享歌曲、歌单与收藏，队列和主题等偏好由各自浏览器保存；当前没有 Android／iOS 原生客户端或独立手机运行时。连接方式见[启动与访问](docs/产品/启动与访问.md)。

## 使用说明

- B站和 YouTube 使用非官方接入方式，功能可用性受平台接口、账号权限、地区和网络影响。
- YouTube 默认关闭，启用前需配置网络和外部取源工具，见[来源工具与账号](docs/运维/运行维护.md#来源工具与账号)。
- 开启B站收藏夹关联后，本地新增和删除可能同步修改远端收藏夹；请先核对关联预览。
- 当前不提供音视频下载或完整离线曲库。歌单 JSON 仅备份歌曲资料；完整备份请退出程序后复制整个 `data/`。

## 源码启动

需要 Windows、Git 和 Node.js `>=24.15.0`（含 npm）。

```powershell
git clone https://github.com/xiaoxiaosu25/slowtune.git
cd slowtune
npm ci
npm run desktop:build
npm run desktop
```

构建完成后，也可双击仓库根目录的 `一键启动.cmd` 打开应用。
